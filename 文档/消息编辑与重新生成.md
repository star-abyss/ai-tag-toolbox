# 消息编辑与重新生成

用户和 AI 正文旁提供「编辑」入口。编辑器只修改文本，原消息的图片、推理和工具记录由会话模块保留；保存只写文本，不自动发送。取消恢复展示状态。

2026-10-18 图标布局：编辑入口复用现有笔形图标，重新生成使用 `↻`。AI 消息操作行按「复制、修改、重新生成、时间」排列，用户消息按「复制、修改、时间」排列。常态入口无文字或按钮边框，悬浮提示与读屏名称保留；打开编辑器后的保存、取消仍显示文字。失败轮次没有正文操作行时，重新生成图标显示在错误下方。

AI 每个轮次只显示一个「重新生成」入口。调用时带当前会话标识和轮次标识；会话模块用该轮用户消息的当前内容及之前历史、当前模型与提示词重新执行该轮，替换该轮回复并保留之后的对话。工具可能再次执行。该动作在运行期间不可用。

界面从宿主动作表读取「改消息」「重新生成」动作及其说明。`对话管理.js` 以这些动作名复用 `ConversationClient` 的 `/toolbox/调` 调用，不增设 HTTP 路由。每次按钮创建时捕获会话和目标 ID；切换会话会重建消息节点及编辑状态。编辑框本身按稳定节点复用，所以草稿保存或流更新不会冲掉正在输入的内容。

验证：`node 程序/对接层/界面/试/消息编辑.js` 使用隔离服务与真实 Edge 验证用户/AI 编辑入口、附件保留、编辑输入重绘保留、每轮重新生成入口及运行状态禁用。真实动作回执与后续历史保留由会话动作集成验证。

2026-10-18 主代理验收：会话模块 31 项、17 个动作接口契约、装配 39 项、既有 AI 对话 HTTP 回归、新增消息编辑浏览器专项与 `试/会话编辑HTTP.js` 通过。HTTP 专项核对编辑后的用户/AI 文本进入后续实际请求，较早轮次重生成排除旧回复与后文、重算世界书参考、保留后文、首次请求失败保留原回复，以及重启后记录保持。运行版在原文件夹更新至 V1.5.14，存档位置不变；新增后端动作在本地服务重启后加载。
