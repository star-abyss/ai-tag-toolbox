# ComfyUI 设置与助手栏

## 目标与页面布局

助手页是对话和出图入口，ComfyUI 设置页是用户管理连接、工作流与绘制参数的入口。技术参数由用户调整，程序按保存值运行，不把这份配置发给 AI。

助手顶部生成栏只保留两个控件：`启用绘图` 与 `绘制数量`。两者并排排列，按内容占宽；删除原来的多行卡片、重复连接状态、工作流名称、额度说明、最多轮数与自动迭代复选框。小屏允许整体换行，禁止横向溢出。连接故障通过操作回执和设置页查看，设置页仍可从现有导航进入。

## 设置页保留与删除

| 区域 | 保留的用户能力 | 精简方式 |
| --- | --- | --- |
| 连接 | 地址、保存、测试连接、打开 ComfyUI、连接与队列状态 | 一组连接控件，地址保存真正影响服务端请求并持久化 |
| 工作流 | 导入 JSON 或带工作流 PNG、查看当前识别状态、复制导出、清空 | 单份工作流，不显示虚假的档案管理 |
| 节点参数 | 尺寸、步数、CFG、种子、采样器、调度器、模型、LoRA，以及工作流内其他实际参数 | 按实际节点分组动态呈现；不再保留一排不生效的固定覆盖框 |
| 迭代设置 | 最多生成轮数、允许自动迭代 | 从助手页移入此页，继续使用原有统一生成设置 |
| 高级编辑 | 原始工作流 JSON 查看、编辑、明确保存 | 折叠区；修改未保存前不覆盖节点表或运行值 |

删除当前实现没有接通的控件及其空适配方法：多档案与另存、读取画布和桥接说明、取消读取、原样/指定输入/旧版三种模式、手动输入映射、独立覆盖参数表、生成负面 Tag、恢复查询、停止等待、历史工作流。保留真实 JSON/PNG 导入和同一个绘画业务入口，不制造第二条出图路径。

## 参数的所有权与保存

工作流是节点参数唯一来源。设置页读取模块返回的节点、字段名、类型、当前值与选项；修改通过 `/toolbox/调` 调用 ComfyUI 模块 `参数` 动作，写回当前源图，再保存到个人数据目录 `ComfyUI/工作流.json`。不在浏览器另外保存一张参数覆盖表。

API 工作流修改对应节点的 `inputs`。界面工作流修改对应 widget，并保留节点位置、连线与图元信息。节点定义用于映射标准控件、枚举和数值类型；种子后的控制选项、PrimitiveNode、自定义控件映射分别按其真实结构处理。连接输入显示其连接关系，直接字段编辑不能断开连接；复杂结构仍可使用高级 JSON 编辑。未知且无法可靠映射的控件显示说明，不猜测写入位置。

绘制数量仍以统一生成设置为准，运行时覆盖识别出的批量入口；节点表中的批量值是工作流原值，页面说明该运行规则。提示词字段是图中的默认值，AI 生成时只写正向、负向与参考图等内容入口。不会把用户设定的采样技术参数变成 AI 工具参数。

ComfyUI 地址存于个人 `设置.json`，装配层传递给 HTTP 适配器，不进入模型工具参数。已有出图进行时不切换服务地址；设置页明确显示保存结果和失败原因。工作流、生成开关与迭代设置仍保存在现有 ComfyUI 存档，不迁移、不复制用户数据。

## AI 可见边界

AI 获得内容相关工具：正向提示词、负向提示词、参考图号，以及当前任务的普通结果。工具定义不包含地址、模型文件、节点参数、工作流 JSON、绘制数量和迭代设置。系统消息、发送预览、绘画工具回执不附加这些配置或额度快照；旧会话中已有的绘画回执在再次投影给模型时也移除配置快照。

运行仍执行用户选择的绘制数量、轮数和开关。不能继续时返回不包含设置值的一般结果；用户可在设置页调整。实际产出的图片、图号和生成成功/失败信息仍是正常业务结果。用户自己写入聊天或世界书的文字不自动改写。

## 验收与交付

1. 使用隔离数据与模拟 ComfyUI，助手页自然进入后只显示两项生成控件；桌面和窄窗口检查实际尺寸与溢出，不通过强制显示或填充示例文字制造验收画面。
2. 从设置页修改实际节点参数；刷新页面、重启服务后保持；模拟 `/prompt` 收到修改后的值，UI 工作流的布局与连线保持。
3. 更改连接地址后，后端请求使用新地址；设置持久化；无效保存给出明确回执。
4. 模拟模型检查实际请求、工具定义、当前与历史绘画回执、发送预览，确认没有自动注入用户技术设置。
5. 回归绘图开关、生成设置、工作流导入、会话执行和 ComfyUI 模块检查。保留客户端事件隔离修复，不向用户真实 ComfyUI 排队。
6. 完成代码审查，递增版本，桌面生成包含模型及已安装依赖的新包；从该包启动隔离服务复验关键入口。验收记录写入 `临时/`。
