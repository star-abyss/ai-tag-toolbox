# ComfyUI 页面精简建议

本文件是对当前界面与真实调用链的分析，尚未实施配置页重排。

## 现状

当前页面同时呈现工作流配置、旧版多工作流管理和未接通的画布桥接控件。`我们的模块.js` 固定返回单份工作流、`runMode:'legacy'` 和空输入映射；视图仍据此绘制完整的旧版工作区。

| 区域 | 当前行为 | 建议 |
|---|---|---|
| 连接状态、版本、队列、测试连接 | 真实查询 ComfyUI | 合成一行保留 |
| 启用绘图 | 真正控制新出图请求 | 保留，放在顶部 |
| ComfyUI 地址 | 页面更新前端内存，服务仍使用装配配置的地址 | 保留能力，修改时接通实际服务配置 |
| 导入 JSON、导入带工作流 PNG | 真正解析并保存当前工作流 | 合并为一个导入入口下的两种来源 |
| 当前工作流与正向、负向、参考图、批量入口识别结果 | 模块已有识别能力 | 简单展示 |
| 复制、清空、查看或编辑 JSON | 有实际工作流操作能力 | 放到更多操作或单一高级区 |
| 本机那一份下拉、另存名称、另存为常用 | 单份清单；另存明确返回未实现 | 删除这些管理控件 |
| 读取当前画布、取消读取、桥接安装说明 | 画布状态固定为空；读取失败，取消为空操作 | 从当前版本页面删除 |
| 原样运行、指定输入、旧版兼容三种模式 | 模式固定，更新不执行模式或输入映射 | 删除模式选择与输入映射编辑区 |
| 恢复查询、停止等待、历史工作流 | 无待恢复任务；停止为空操作；历史为空或失败 | 删除这些未接通控件 |
| 生成负面 Tag | 设置字段没有进入实际保存与出图调用 | 删除 |
| 尺寸、步数、CFG、种子、采样器、调度器 | 当前运行入口没有把这些前端参数作为实际覆盖传给模块 | 删除这排参数，保留工作流中的原有值 |
| 批量数量 | 已有每轮生成张数的统一设置 | 删除此处重复入口 |
| 运行工作流、正负提示词 | 实际复用绘画业务生成，并非按界面三种模式运行 | 手动生成集中在助手页，配置页负责连接和工作流 |

## 建议布局

顶部：启用绘图、连接地址、测试连接、打开 ComfyUI。

主体：当前工作流、导入 JSON 或 PNG、保存状态、模块识别结果。

更多操作：复制或导出、清空。

一个默认折叠的高级区：工作流 JSON 查看与编辑。

页面控件精简时，应一并移除对应的空方法、重复事件绑定和不生效的状态字段；已经可用的统一模块与绘画业务入口继续复用。
