## 6.4 提示词页：主 AI 预设的另一面

旧版那一页有 7 个条目 + 副 AI 四段。**跟我们这一侧对得上的只有两样**，别的**不画**：

| 那一页上的东西 | 我们这一侧是什么 |
|---|---|
| 人设 | 预设的 `身份` → 系统提示词 order 0 |
| 流程规则 | 预设的 `流程` → order 5100 |
| 「提示词组」 | **一份主 AI 预设**（切换 / 新增 / 重命名 / 删除 / 导入 / 导出） |
| ~~工具注册表~~ | 工具说明由 DSH 按工具定义现生成，界面这一侧拿不到原文 → **隐藏** |
| ~~副提示词四段~~（文生图 / 画师品质 / 识图 / 翻译） | 那些提示词住**世界书**（三份默认：翻译 · 识图 · 文生图）→ **隐藏** |

**改一个字就落一次盘**（`预设({动作:'改'})` + `存`）：这一页没有"保存"钮，等一次别的动作会把字丢了。
**「提示词组」那几个动作也要跟着 `存`** —— 模块的新建 / 改名 / 删 / 换只落在草稿上，不存就等于没做。

**只读默认那一份**（`$默认:主AI`，随程序走、没有写路径）是**合法且常见的起手状态**（用户还没建过预设时
生效的就是它）。这时两格只读、五个写钮灰着，页面上说清出路：**按「新增提示词组」抄一份出来**
（模块的 `新建` 不给 `源` 就是从只读默认抄一份快照）。这一条与「主 AI」面板口径一致 ——
**两块屏幕对同一份数据不能有两种说法**。
