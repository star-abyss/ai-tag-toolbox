# 存储布局

## 程序与模型

`启动.cmd` 与 `程序/` 提供运行入口和代码。识图模型位于启动器同层的 `模型/识图/`，翻译模型位于 `模型/翻译/`。模型目录不随个人数据位置变化。

WD EVA02 模型目录包含 `wd-eva02*.onnx` 与 `tags-canary.json`。opus-mt 目录包含 `opus-mt-en-zh/` 和 `opus-mt-zh-en/`，每个方向提供权重、配置、分词器与词表。详见 [模型说明](../模型/说明.md)。

## 个人数据

默认数据根目录为 `%LOCALAPPDATA%\工具箱\`，包括：

| 位置 | 保存内容 |
|---|---|
| `设置.json` | 界面选项和本地模型选择 |
| `API/` | 服务商地址、模型、密钥与模型能力表 |
| `会话/` | 消息、草稿和轮次 |
| `图库/` | 图库、会话图片及附件 |
| `标签/` | 标签记录、分类、收藏、注释和用户修改 |
| `预设/` | 主 AI 设置和工具文本 |
| `世界书/` | 用户创建、导入或编辑的世界书 |
| `ComfyUI/` | 工作流和连接、生成设置 |

位置文件固定为 `%LOCALAPPDATA%\工具箱\位置.json`。在界面更改数据根后，下次启动使用新目录。程序不会自动搬动现有数据；要保留数据时，先自行复制整个数据根，再切换位置。

API 密钥以本机配置文件保存。备份个人数据目录会包含这些密钥、会话和图片，备份由用户自己保管。

浏览器还会在当前页面来源下保存界面缓存和本地状态；浏览器缓存不包含在桌面程序包中。用户数据的文件目录以界面“存储位置”显示为准。

## 更新与备份

更新程序时保留 `模型/`；若换到新的程序目录，把原 `模型/` 一起复制过去。默认个人数据目录独立于程序包，更换程序目录后仍使用原来的数据。备份时复制整个个人数据根；位置文件用于记住下次启动位置。

桌面发行包由运行代码、内置资源、运行依赖和正式说明组成。可包含独立的 `模型/` 目录；源码仓库只保留模型放置说明。个人数据、开发记录、截图、测试与 Git 元数据不放入桌面包。
