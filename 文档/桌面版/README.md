# AI 绘画 Tag 工具箱

本地运行的 AI 绘画工具，提供 Danbooru 标签检索与整理、ComfyUI 工作流出图、本地识图和翻译，以及调用绘画工具的 AI 对话。

在 Windows 安装 Node.js 22 或更新版本，双击本目录的 `启动.cmd`。服务启动后会自动打开系统浏览器；关闭控制台即可退出程序。运行依赖已包含在桌面包内。

首次使用时，在设置中填写 ComfyUI 地址、导入工作流；使用 AI 功能时填写自己的 API 地址、密钥和模型。API 设置与其他个人数据统一保存在本机个人数据目录。

本地模型放在启动器同层的 `模型/识图/` 和 `模型/翻译/`，可在界面刷新并选择。未放置模型时仍可使用标签、图库、ComfyUI 和 API 功能。识图和本地翻译需要对应模型。

- [模块架构](文档/模块架构.md)：模块职责、装配与数据流。
- [存储布局](文档/存储布局.md)：个人数据、模型和更新方式。

应用版本由 `程序/version.json` 提供，界面显示同一版本。

V1.5.20 支持 Flux2 空潜空间工作流的批量生成，保留原有工作流的批量处理；文生图使用独立模型请求及该请求启用的世界书。主 AI、翻译、识图和文生图均支持按顺序启用多本世界书。文生图请求需在 API 设置中选择服务商与模型。
