# 模块架构

七个能力模块平级，彼此不直接依赖。主 AI 定义预设与工具设置，会话模块管理交互记录，装配层提供模块之间需要的端口；界面使用同一宿主门面。

| 模块 | 职责 | 对外入口 |
|---|---|---|
| tag模块 | 标签记录、检索、分类、收藏和注释 | `程序/tag模块/index.js` |
| 图片模块 | 图片内容、引用、图库和会话图片 | `程序/图片模块/index.js` |
| 世界书模块 | 书与条目的管理、启用、命中和提示词落点 | `程序/世界书模块/index.js` |
| 装订模块 | 文本切分、格式保留与译文拼装 | `程序/装订模块/index.js` |
| comfyUI模块 | 工作流、节点接口、队列、生成和图片取回 | `程序/comfyUI模块/index.js` |
| 翻译模块 | 使用注入的切分、查词和翻译引擎处理文本 | `程序/翻译模块/index.js` |
| 识图模块 | 图片元数据、本地标签与 API 看图 | `程序/识图模块/index.js` |
| 主AI模块 | 主 AI 预设、工具定义和用户设置 | `程序/主AI模块/index.js` |
| 会话模块 | 消息、轮次、草稿、执行状态、会话归档 | `程序/会话模块/index.js` |
| 对接层 | 装配模块、调用服务商、模型引擎和绘画业务 | `程序/对接层/宿主.js` |
| 界面层 | 页面、本机 HTTP 服务、文件字节和长任务 | `程序/对接层/界面/服务.js` |

## 模块接口

每个能力模块通过自己的 `index.js` 交出门面和一份动作清单，内部核心处理业务，适配器负责文件或网络。外部依赖由装配层传入。模块动作参数使用标识，图片通过引用和会话内图号传递。

界面模块动作统一发送到 `/toolbox/调`，动作名称、参数和控件说明来自宿主。链路表与服务商分别使用 `/toolbox/链路` 和 `/toolbox/服务商`；数据位置和用户设置由存储接口管理。

## AI 与绘画

主 AI 的提示词内容由启用的世界书提供。会话执行器固定本轮设置、拼装系统消息与工具定义、调用服务商、执行返回的绘画工具，再将工具结果放回会话。界面可以查看发送预览与工具调用记录。

绘画业务连接 ComfyUI 门面和图片门面：生成图片后取回字节，保存为会话图片，再把可见的图号和结果交给 AI。生成张数、轮数与自动迭代由用户在界面设置。

## 保存与模型

个人数据目录由 `程序/对接层/位置.js` 统一交给宿主和各模块。标签基础种子随程序发布，首次使用时复制到个人数据目录，此后的修改写入个人副本。

本地推理由 `程序/对接层/模型引擎/` 负责，模型文件在包根 `模型/`，代码中不包含用户模型权重。识图与翻译引擎按目录中的文件识别模型，界面保存用户的模型选择。
