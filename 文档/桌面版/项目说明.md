# 项目说明

工具箱是个人使用的本地 AI 绘画应用。Node.js 运行本机服务，系统浏览器提供操作界面。模块通过宿主装配，数据以本机文件保存。

## 功能

| 功能 | 使用入口 |
|---|---|
| 标签检索、分类、中文对照、标签组和角色库 | 标签页面及分类、收藏面板 |
| 上传图片、图库收藏、图片元数据和本地打标 | 识图页面与图库 |
| 提示词切分、本地翻译与 API 翻译 | 翻译页面 |
| ComfyUI 连接、工作流导入、节点参数和出图 | ComfyUI 设置与助手生成栏 |
| 世界书、主 AI 工具与发送预览 | AI 提示词设置 |
| 会话、图片附件、编辑消息、重新生成与导入导出 | 助手与对话档案 |
| 服务商、模型与密钥设置 | API 设置 |

## 启动

需要 Windows、Node.js 22 或更新版本，以及系统浏览器。双击根目录 `启动.cmd`，程序在控制台前台运行并自动打开页面；关闭控制台结束服务。默认监听本机 `127.0.0.1:8790`。

ComfyUI、API 服务商和本地模型由用户按需要配置。ComfyUI 地址可以在界面修改；API 地址与模型名称也由用户填写或从服务商获取。
