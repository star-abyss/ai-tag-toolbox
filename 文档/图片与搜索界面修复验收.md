# 图片与搜索界面修复验收 · V1.5.7

日期：2026-10-17。交付目录：`<桌面>/工具箱-1.5.7`。

## 原因与修复

1. 聊天消息中的图片原为静态 `div/img`，未绑定查看动作；待发送图片已有打开回调，但宿主未提供该回调。消息图片现为原生按钮，经挂载层调用已有原图查看器，待发区使用相同入口。
2. 消息默认取 160px 缩略图；适配层还将 `preview` 映射为同一缩略图地址，查看器因而也只能取得小图。现分为小附件 160px、聊天预览 768px、查看器 original 三种用途；聊天图片最大按 360px 等比展示，查看器读取原始文件。
3. 搜索下拉精度与正则开关均未传到底层。现删除未接入的控件、状态和样式；标签仍按完整名称、词段、连写及包含匹配分档排序，角色仍使用当前的包含匹配。
4. 图片角标与清空对话原使用字体字符。现复用线条 SVG，图片移除按钮 22px、图标 12px，清空会话按钮 32px、图标 16px，固定居中。清空会话的说明、确认和图片保留语义沿用原链路。

## 验收依据

| 操作 | 应有结果 |
|---|---|
| 在会话中点击发送的图片 | 打开大图查看器，读取对应原图 |
| 点击生成结果中的图片 | 使用相同查看器，按该图片标识加载原图 |
| 刷新页面后点击历史图片 | 仍可打开，不依赖发送时的临时状态 |
| 点击待发送区缩略图 | 打开对应原图；关闭后附件仍保留 |
| 按 Esc | 关闭查看器 |
| 浏览聊天图片 | 显示较清晰的预览，保持纵横比，窄窗不溢出 |
| 使用搜索框 | Enter、搜索按钮和清除搜索正常；没有未接入的模式选项 |
| 悬停图片移除/清空会话按钮 | SVG 居中，点击区完整，悬停和键盘聚焦状态可见；清空会话说明图片保留 |
