# 绘画业务与模型工具

日期：2026-10-17。现行实现位于 `程序/对接层/绘画业务.js`，模块仍平级提供自己的门面；模块动作清单供宿主装配和界面管理使用，不直接生成模型工具。

## 定义与执行

V1.5.15 的生成设置、计数口径、流程文本与验证入口见 [生成张数与自动迭代](生成张数与自动迭代.md)。`造绘画业务` 可注入本次 `生成设置` 和 `onGenerationState`；`准备()` 在模型首次请求前读取设置快照，`状态()` 返回快照与额度副本。`drawing_generate` 每次实际提交计一轮，输入张数来自设置；自动迭代关闭时有效上限为 1。成功和失败回执均带 `生成状态`，`drawing_info` 同时报告批量输入能力与额度。

`导出绘画工具表()` 给出用途摘要、逐参数schema和说明。`造绘画业务({门面,sessionId,提问,signal})` 将同一组定义绑定到当前会话的执行器，返回 `{工具表,执行}`。业务执行使用模块公开门面，不解析节点图、不跨模块访问内部状态。

| 模型工具 | 用途 | 主要输入 |
|---|---|---|
| tags_search | 标签与角色候选，含命中类型及实际命中词 | 查询、数量可选 |
| tags_get | 某个候选的标签或角色详情 | 标识 |
| images_list | 当前会话图号、名称和尺寸 | 无 |
| images_view | 当前会话图像进入视觉请求 | 图号 |
| drawing_info | 当前绘画输入能力及绘图状态，只读 | 无 |
| drawing_generate | 生图、取回、保存入会话、图片回传 | 正向、负向可选、参考图图号可选 |
| ask_user | 等待用户明确选择，可取消 | 问题、选项数组 |
| translate_text | 翻译文本并返回对照 | 文本、方向可选 |
| vision_tag | 本地识图标签及概率 | 图号、阈值可选 |
| vision_describe | 视觉描述与标签 | 图号、提示可选 |

分类维护、词库管理、图库管理、节点定义、工作流编辑、开关设置等操作不在这份定义中。执行器也没有“模块名+动作名”的通用路由参数。

工具schema由业务定义持有。主AI预设仅记录启用、说明与顺序偏好，每次读时投影当前定义；旧的模块动作快照不能重新生成能力。`tools:[]` 表示无偏好覆盖，停用用各项明确的启用差异表达。

## 图片与会话

图号和高水位属于图片模块。`列会话图` 首次给旧素材补号，之后由所有入会话的保存操作原生分配；删除不挪号，不复用。模型只填当前会话图号，宿主注入会话ID与内部引用。

业务结果与持久历史保存 `{type:'session-image',imageId}` 公共标记。会话请求投影在发送前读字节，产生原生image内容，经服务商转换为image_url；原图base64不写回会话。

归档v2保存每项图片number与会话imageNumberHighWater。导入创建新imageId，重映射公共标记，按原号导入并恢复高水位；不猜测没有编号信息的旧归档。

手动生图经 `/toolbox/调` 的 `drawing/生成({会话,正向,负向?,参考图?})`，与模型执行同一drawing_generate操作。管理界面仍经模块门面存取配置。

## 提问与停止

会话模块提供待答问题、回答问题、取消问题三个运行时动作，问题按会话及问题ID定位。ask_user等待该会话的回答；取消先记录失败回执，再停止本轮剩余未执行工具。切换页面或回答其他会话不会将答案交给错误的调用。

## 两个宿主入口

桌面对话由会话执行器绑定sessionId、提问端口和signal，使用完整10项业务能力。每次请求重新读取素材清单；已撤销的非业务工具及配对回执不再投影给模型，磁盘原文保留。

DSH插件登记器将execute第二参数原样交给业务执行器。插件按公开ToolRunContext中的agent.session.id及signal绑定会话；若显式传入 `config.用户提问({会话,问题,选项,signal})`，才登记ask_user，未传则不生成悬空提问能力。该回调返回与业务一致的 `{ok,data}` 或失败信封。

本机未安装可运行的DSH。本轮验证了契约替身中的上下文隔离与提问端口注入，未声称已在外部DSH版本中完成实机验收。桌面独立宿主和它的会话执行链路单独验证。
