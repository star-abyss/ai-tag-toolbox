# 存储与交付

用户模型位于仓库根目录 `模型/识图/` 与 `模型/翻译/`，WD EVA02 和 opus-mt 按文件结构自动发现，不需要 `模型.json`。个人数据默认位于 `%LOCALAPPDATA%/工具箱/`，固定位置设置文件为 `%LOCALAPPDATA%/工具箱/位置.json`；`设置.json` 保存界面选项和模型选择。首次启动时，标签模块将 `程序/内置资源/标签/` 的干净基础种子复制到个人数据根的 `标签/`，此后标签读写使用这份个人数据。用户可以在界面改数据根目录，改动下次启动生效，不自动搬文件。详细布局、迁移方式与打包规则见 [存储布局.md](存储布局.md)。

# 二、每个模块有哪些文件

**形状是同一个，每个模块按自己那个端口换掉"外部世界"那几件。**
有盘的三个（标签 / 图片 / 世界书）与主 AI 是 `adapter-file.js` + `adapter-memory.js`；
装订与翻译是 `adapter-fake.js` + `adapter-real.js`；comfyUI 是 `adapter-http.js` + `adapter-memory.js`；
识图也是 `adapter-fake.js` + `adapter-real.js`，另多一个纯函数 `元数据.js`。

| 文件 | 每一份都有吗 | 干什么 |
|---|---|---|
| `index.js` | ✅ 十二份 | **门面。对外只有这一个文件。** 出口 `Object.freeze`，不递内部件 |
| `core.js` | ✅ 十二份 | 核心。纯逻辑，**不 require fs / path，不 require 别的模块** |
| `port.js` | ✅ 十二份 | 端口契约：核心要求装配层提供什么 |
| `graph.js` | 只有 comfyUI | 图：两种形态互转 · 认口 · 填口（纯函数） |
| `元数据.js` | 只有识图 | PNG 文字块解析（纯函数，只吃字节） |
| `文本.js` | 只有装订 | 共用切分、原始范围与拼装；由装配层将门面文本处理对象注入翻译模块 |
| `adapter-file.js` | 标签 · 图片 · 世界书 · 主 AI | 文件适配器。**唯一 require fs / path 的地方** |
| `adapter-memory.js` | 标签 · 图片 · 世界书 · comfyUI · 主 AI | 内存适配器。证明核心真的不依赖盘 / 不依赖真网络 |
| `adapter-http.js` | 只有 comfyUI | HTTP 适配器。**唯一发请求的地方** |
| `adapter-fake.js` · `adapter-real.js` | 装订 · 翻译 · 识图 | 假适配器（自包含，自检靠它）/ 真实适配器（接装配层递来的函数） |
| `test/run.js` | ✅ 十二份 | 功能自检。自建数据、自清数据，失败非零退出 |
| `test/接口.js` | 图片 · comfyUI | 按契约逐个字段校验接口形状 |
| `test/造图.js` · `test/默认们.js` · `test/假模块.js` | 识图 · 世界书 · 主 AI | 那一份自检自己的小工具 |
| `tools/*.js` | 标签 · 图片 · 世界书 · comfyUI · 识图 | 探针、演示、验收脚本（装订 / 翻译 / 主 AI 没有） |
| `README.md` | ✅ 十二份 | 给 AI 的上手指南（十节骨架） |
| `<模块名>设计.md` | ✅ 十二份 | 设计规范。自包含，不引用别的模块的设计 |
| `接口.md` 或 `对外接口.md` | ✅ 十二份 | 契约：字段名 / 类型 / 必填 / 错误码 |
| `调用示例.md` | 八份 | 调用示例与错误表（标签模块并进了 `对外接口.md`） |
| `package.json` | ✅ 十二份 | 名字与 `npm test` |
| `assets/` | 世界书 · 主 AI | 只读默认：三份世界书 `翻译` · `识图` · `文生图` / 一份预设 `主AI.json` |
| `data/` | 只有标签 | 运行时数据目录；可能包含用户修改，由 `.gitignore` 忽略。干净基础种子在 `程序/内置资源/标签/` 并纳入 GitHub |

# 三、九个模块：一句话 + 入口

| 模块 | 一句话 | 对外只有 | 自检 |
|---|---|---|---|
| **标签** `程序/tag模块/` | 词的库与检索 | `query` · `recognize` 等 33 个动作 | 66 条 |
| **图片** `程序/图片模块/` | 图的存放与取回 | `列` · `存` · `取内容` 等 12 个动作 | 41 + 24 条 |
| **世界书** `程序/世界书模块/` | 一个请求挂几本世界书，按文本挑出带落点的条目 | `执行` 等 10 个动作 | 59 条 |
| **装订** `程序/装订模块/` | 切分 · 查词 · 交给 AI · 拼回 | `切分` · `装订` 两个动作 | 61 条 |
| **comfyUI** `程序/comfyUI模块/` | 读工作流 · 认三个口 · 出图 · 取图 | `探活` · `认` · `出图` · `取图` 等 10 个动作 | 134 + 31 条 |
| **翻译** `程序/翻译模块/` | 切分 · 查词 · 查不到的交给本地模型 · 拼回 | `看模型` · `本地译` · `切分` 三个动作 | 60 条 |
| **识图** `程序/识图模块/` | 本地打标 · 读元数据 · 交给模型看图 | `看模型` · `认图` · `读元数据` · `看图` 四个动作 | 37 条 |
| **主 AI** `程序/主AI模块/` | 一份预设：身份 · 流程 · 工具表 · 世界书 · 模型 | `执行` · `读` · `预设` · `工具` 等 10 个动作 | 62 条 |
| **对接层** `程序/对接层/` | 装配层：装模块 · 登记工具 · 注册段 · 调度 · 模型引擎 | 不是模块：DSH 的插件出口 `apply(ctx, config)` | 33 条 |
| **界面** `程序/对接层/界面/` | 本地服务 + 浏览器页面：十二块面板，84 个动作点得着 | 不是模块：一份 HTTP 路由表 + 一份面板契约 | 123 条 |

**七个能力模块互不认识、互不依赖。** 谁都不 `require` 别人的内部件。
**主 AI 模块与对接层不算那七个**：前者是"这个 AI 是什么"的定义，后者是把定义接到运行时上的装配层。

# 七、哪条不能动（跨模块的四条）

| # | 规则 | 违反的后果 |
|---|---|---|
| 1 | **核心不许 `require fs` / `path`** | 内存适配器跑不通，"端口封住了"就只是说法 |
| 2 | **对外参数只能是标识，不许出现路径 / 地址** | 模型能填地址，就能读机器上任何文件 |
| 3 | **一个模块对外只有 `index.js`**，出口 `Object.freeze` | 内部件被递出去，边界就没了 |
| 4 | **失败一律 `{ ok:false, reason, code }`，不抛错**（装配阶段除外） | 调用方分辨不出失败原因 |

各模块自己那几条，在各自 `README.md` 的"哪条不能动"那节。
