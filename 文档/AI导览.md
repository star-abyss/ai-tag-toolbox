# 一、一分钟认门

目录总览见 [README.md](../README.md#一分钟认门)。运行代码与资源位于 `程序/`，各模块与对接层保持平级；现行说明位于 `文档/`，维护脚本位于 `scripts/`，工作备份与截图位于 `临时/`。

**七个能力模块互不认识、互不依赖。** 有盘的三个结构一模一样（`index.js` / `core.js` / `port.js` / 两个适配器 / 四份文档）；装订、comfyUI、翻译、识图都不碰盘，各自把"存储那两件"换成自己要的那几件（端口全是递进来的函数）。

| 文件 | 行数 | 管什么 |

| `index.js` | 251 | 门面 + 动作表（12 个动作） |

## 3.3 世界书模块 `程序/世界书模块/`

**管什么**：一个请求挂几本世界书，来一次调用就把它们筛一筛，交出**带落点的条目**。**不拼装、不对模型说话、不认识主 AI。**

| 文件 | 行数 | 管什么 |
|---|---:|---|
| `index.js` | 179 | 门面 + 动作表（10 个动作） |
| `core.js` | 569 | 核心：书、条目、启用列表、草稿 / 存档 |
| `worldbook.js` | 257 | 解析 / 归一化 / 筛选（纯函数） |
| `port.js` | 45 | 端口（`readState` / `writeState` / `listDefaults` / `readDefault`） |
| `adapter-file.js` | 127 | 文件端口：`<根>/世界书.json` + `<默认目录>/<名字>.json` |
| `adapter-memory.js` | 61 | 内存端口 |
| `assets/世界书/` | —— | 四份只读默认：`主AI` · `文生图` · `翻译` · `识图` |

**动作名（10）**：`执行` · `读` · `表` · `测` · `书` · `条目` · `存` · `丢` · `重读` · `状态`
**`书` 六个子动作**：`换` · `导入` · `新建` · `改名` · `删` · `导出`　·　**`条目` 四个**：`加` · `改` · `删` · `移`

**两个状态**：`存档`（端口里那份，**`执行` 只用它**）/ `草稿`（内存里那份，`读` / `测` 与全部改动作用在它上面）。

**它交出去的**：`{ 请求, 书, 命中 }`，命中里是 `{ 文本, 落点, 深度?, 角色?, 书 }`。**没有"一段拼好的文本"这个出口**——拼装归上层。

**四条容易踩的**：

| # | 规矩 |
|---|---|
| 1 | **有哪几本书由目录回答**，代码里没有清单；文件名就是书的名字 |
| 2 | **`执行` 读存档，`测` 读草稿** —— 前者是上层要的，后者是界面预览 |
| 3 | **导入永不覆盖**：只新增，撞名加号；归属按位置算（导出一份默认再导入 ⇒ 它就是用户的） |
| 4 | **落点一律原样带出去**：模块不解释"能落在哪"，那是上层的事 |

## 3.4 三份默认世界书 `程序/世界书模块/assets/世界书/`

| 文件 | 名字 | 条目 |
|---|---|---|
| `翻译.json` | 翻译 | 2 条（翻译器 + 方向总则；**初稿**） |
| `识图.json` | 识图 | 1 条（恒常） |
| `文生图.json` | 文生图 | 5 条（2 条恒常、3 条带条件） |

## 3.5 装订模块 `程序/装订模块/`

**管什么**：把一段文本切开，查得到的词换成库里的中文名，查不到的交给 AI，再按原样拼回去。
**没有盘**，所以端口是两个递进来的函数，不是存储。

| 文件 | 行数 | 管什么 |
|---|---:|---|
| `index.js` | 129 | 门面 + 动作表（2 个动作） |
| `core.js` | — | AI 报文解析、方向与查词、一次装订编排 |
| `文本.js` | — | 共用切分、原始 UTF-16 范围、按词范围拼装与方向判断 |
| `port.js` | 40 | 端口：`查词` 与 `AI翻译` 的名字与形状 |
| `adapter-fake.js` | 76 | 假适配器：自包含，跑自检用；返回形状可切 |
| `adapter-real.js` | 66 | 真实适配器：把两个端口接到装配层递来的函数上 |

**动作名（2）**：`切分`（同步、纯）· `装订`（异步）

**一次装订六步**：切分 → 查词 → 投影报文 → 发送 → 归位 → 拼回。
**表只活在一次装订里**；一次装订同时在飞的只有一个（`TEXT_BUSY`）。

**报文**：`{ source, words, from, to }`——只投影「词」这一列，不带值、不带壳、不带空行；查到的词根本不发出去。

## 3.6 comfyUI 模块 `程序/comfyUI模块/`

**管什么**：把一张 ComfyUI 工作流读进来，认出正 / 负 / 图三个口，填进去跑图，把图取回来。
**不认识别的模块**：地址与存档都从装配层递进来。

| 文件 | 行数 | 管什么 |
|---|---:|---|
| `index.js` | 210 | 门面 + 动作表（10 个动作） |
| `core.js` | 287 | 核心：连接 / 存档 / 认口 / 一次出图的编排 |
| `graph.js` | 629 | 图：两种形态互转 · 认口 · 填口（纯函数） |
| `port.js` | 60 | 端口契约（七个方法）+ 异常归类的词 |
| `adapter-http.js` | 271 | HTTP 适配器。**唯一发请求的地方** |
| `adapter-memory.js` | 94 | 内存适配器 |

**动作名（10）**：`探活` · `看队列` · `看节点定义` · `存工作流` · `取工作流` · `清工作流` · `认` · `认图` · `出图` · `取图`

**十个动作一律返回 Promise**：直呼成功给数据、失败给 `null`；`run` 给 `{ ok, data }` 信封。

**一次出图五步**：认口 → 填口 → 提交 → 盯到完成 → 报产出。
`出图` 还能接 `信号`（取消）、`onEvent`（进度）、`间隔毫秒`。

## 3.7 翻译模块 `程序/翻译模块/`

**管什么**：一段文本切成一格一格，库里查得到的给中文名，查不到的交给**本地模型**，再按原样拼回。
**它是"不花钱的那条翻译路"**：装订模块那条把查不到的词交给 AI；本模块这条交给本地模型。
**两条路共用文本处理和查词**：装配层递入 `装订.文本处理` 与标签模块的 `recognize`。本地模型按单元标识返回结果，最终译文与范围表同次拼装。

| 文件 | 管什么 |
|---|---|
| `index.js` | 门面 + 动作表（3 个动作） |
| `core.js` | 编排：切分 → 查词 → 挑剩下的 → 交给模型 → 拼回 |
| `port.js` | 端口契约（`文本处理` / `查词` / `译`） |
| `adapter-fake.js` | 自包含的假适配器，自检靠它 |
| `adapter-real.js` | 接装配层递来的文本处理对象与两个可选函数 |

**动作名（3）**：`看模型` · `本地译` · `切分`　（工具名 `translate_models` / `translate_local` / `translate_split`）

**来源与范围**：`表[].出处` 区分库、模型、原词与空项；UI 直接用原文/译文范围高亮。方向、保留与缺失模型结果的行为见 [翻译接口](../程序/翻译模块/接口.md)。

## 3.8 识图模块 `程序/识图模块/`

**管什么**：一张图进来，要么本地模型给它打标，要么把图里藏着的提示词读出来，要么交给模型看。
**三条路分开**（输入与失败表现都不一样）：`读元数据`（不要模型）· `认图`（要本地模型）· `看图`（要一条能看图的链路）。

| 文件 | 管什么 |
|---|---|
| `index.js` | 门面 + 动作表（4 个动作） |
| `core.js` | 四条路的编排 |
| `元数据.js` | PNG 文字块解析（纯函数，认 `tEXt` / `iTXt` / `zTXt`） |
| `port.js` | 端口契约（`取图字节` / `查词` / `tagger` / `看图` / `读元数据`） |
| `adapter-fake.js` · `adapter-real.js` | 假适配器 / 真实适配器 |
| `test/造图.js` | 自检用的小工具：造一张真 PNG（不引第三方库） |

**动作名（4）**：`看模型` · `认图` · `读元数据` · `看图`　（工具名 `vision_models` / `vision_detect` / `vision_metadata` / `vision_ask`）

**位图从哪来不是它的事**：它只交出一个引用，由装配层去图片模块取字节。

## 3.9 主 AI 模块 `程序/主AI模块/`

**管什么**：模型与业务工具设置；身份和工作方式作为主 AI 世界书条目管理。
它保存用户对模型和工具的配置，工具 schema 来自宿主递入的业务定义。**不认识 DSH，也不认识那七个模块。**

| 文件 | 管什么 |
|---|---|
| `index.js` | 门面 + 动作表（10 个对外动作） |
| `core.js` | 核心：预设 / 草稿 / 存档 / 冻结写 / 算工具表 |
| `preset.js` | 预设的归一化与形状计算（纯函数，含工具名 `<模块键>_<动作名>` 的拼法） |
| `port.js` | 端口（`readState` / `writeState` / `listDefaults` / `readDefault` / `moduleActions`） |
| `adapter-file.js` | 文件端口：`<根>/预设.json` + `<默认目录>/<名字>.json` |
| `adapter-memory.js` | 内存端口（证明核心不依赖盘） |
| `assets/预设/主AI.json` | **只读默认设置**：名称与模型工具配置。**工具表由业务定义现算** |

**动作名（10）**：`执行` · `读` · `表` · `测` · `预设` · `工具` · `存` · `丢` · `重读` · `状态`
**`预设` 八个子动作**：`新建` · `复制` · `导入` · `改名` · `删` · `导出` · `改` · `换`　·　**`工具` 五个**：`加` · `改` · `删` · `移` · `重置`

**四条容易踩的**：

| # | 规矩 |
|---|---|
| 1 | **默认那份的工具表是算出来的**：读模块的动作表现算，**不落盘**（没有那份文件，就没有删除、没有改坏） |
| 2 | **`执行` 读存档，`测` 读草稿** —— 上层用前者，界面预览用后者 |
| 3 | **用户那份是一次快照**：之后与模块各走各的，**不迁移、不提醒** |
| 4 | **"读不懂"不许当成"没有"**：存档读不懂 ⇒ 冻结写，只读默认照常可用 |

## 3.10 对接层 `程序/对接层/`

**管什么**：把上面那层定义接到运行时（DSH）上。**它不是模块**，没有动作表，对外就是 DSH 的插件约定。

| 文件 | 管什么 |
|---|---|
| `index.js` | 插件入口：`apply(ctx, config)` 做那四件事 |
| `模块清单.js` | 七个模块怎么装 · **模块键与动作名的对照** |
| `登记工具.js` | 预设的工具表 → DSH 的工具注册表 |
| `调度.js` | 查路由 · 调模型 · 归类失败 · 造装订要的 `AI翻译` |
| `本轮文本.js` | 挂 `agent/inbox/claimed`，记住本步批次 |
| `世界书.js` | 请求 + 文本 → 带落点的条目，按落点分堆 |

| `模型引擎/` | 本地模型：目录扫面 · 翻译 · 识图 · 看图 |

**三条容易踩的**：

| # | 规矩 |

| # | 规则 | 违反的后果 |

| 1 | **核心不许 `require fs` / `path`** | 内存适配器跑不通，"端口封住了"就只是说法 |

| 3 | **一个模块对外只有 `index.js`**，出口 `Object.freeze` | 内部件被递出去，边界就没了 |

| 标签 | **词的库与检索。** 一条记录两种写法归一成一个比对键 |
| 图片 | **图的存放与取回。** 归属写在路径里，所以不需要引用计数 |

| 装订 | **切成一格一格，查得到的换成库译名，查不到的交给 AI，再拼回去。** 报文里没有程序造的符号 |
| comfyUI | **读一张工作流，认正 / 负 / 图三个口，填进去跑，把图取回来。** 采样参数属于图，不属于工具 |
