# ComfyUI 进度与生成栏

V1.5.17。

## 进度事件

工具提交工作流时，HTTP 适配器为自身生成一个 UUID 并通过 `client_id` 发送。相同适配器复用标识，显式传入的 `clientId` 原样使用。任务提交、轮询和取图的入口保持一致。

当前 ComfyUI 服务在没有 `client_id` 时把 `progress` 广播给所有网页，但不发送定向的 `executing {node:null}` 完成消息，网页的采样进度因此可能留在 100%。独立标识使工具进度不会广播到手动网页；网页仍接收自己提交任务的进度和完成通知。工具任务仍在 ComfyUI 队列中，工具箱通过原有任务和会话状态展示执行结果。

此修改不改 ComfyUI 安装或扩展。已经残留的旧进度状态可刷新 ComfyUI 网页清除。

## 生成栏

助手页的每轮张数、最多轮数和自动迭代区域按内容占宽，宽屏最多 620 像素。本轮用量和生成状态可以换行，窄屏保持现有响应式布局。

## 验证

`node 程序/comfyUI模块/test/客户端隔离.js`：真实 HTTP 提交带独立客户端标识；相同实例复用、不同实例分离；显式客户端与工作流元数据保留。

`node 程序/comfyUI模块/test/run.js` 与 `node 程序/comfyUI模块/test/接口.js`：模块行为与接口回归。

`node 程序/对接层/界面/试/生成控件.js`：生成设置行为回归。

实际 ComfyUI 以两个 16×16 的预览任务验证了客户端事件路由：指定客户端收到完成与 `executing {node:null}`，其他客户端收不到该任务的执行事件。这类轻量任务不产生采样进度，完整采样进度条的视觉复测尚未进行；用户任务正在执行时未插入修后探针或中断任务。

生成栏在 1600、700、390 像素视口中检查。宽屏生成栏 620 像素，手机视口中为 349 像素，均无横向溢出。隔离页面临时显示生成栏并填入示例用量文字用于布局检查，未修改个人存档。
