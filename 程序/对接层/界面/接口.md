# 界面层 · 接口

> **这是契约。改实现之前先改它；改完跑 `node 试/无头.js`。**
> 设计理由在 [../../界面设计.md](../../../文档/界面设计.md)；上手指南在 [README.md](README.md)；
> **零件（按钮 / 输入 / 卡片那些类名）在 [组件.md](组件.md)**。

这一层不是模块：它没有 `run()` / `describe()`，对外面就是**一个本地 HTTP 服务**加**一份面板契约**。

---

## 一、怎么起

```bash
node 程序/对接层/界面/服务.js                       # 默认端口 8790
node 程序/对接层/界面/服务.js --端口 8800 --项目根 <程序目录>
node 程序/对接层/界面/服务.js --开                  # 起来之后开浏览器
```

只绑 `127.0.0.1`。启动时打一份令牌到控制台，同时注进页面、下一个 Cookie。

根目录 `启动.cmd` 前台运行 Node 服务，并在服务准备好且开始监听后打开系统浏览器。控制台是本次运行的生命周期；页面关闭不停止服务。关闭控制台后 Node 处理信号、关闭宿主和 HTTP 服务后退出。
`起()` 被导入时不结束调用方进程；调用方可用返回的 `服务.停止()` 清理服务。

## 二、路由

| 路 | 方法 | 收 | 回 |
|---|---|---|---|
| `/` | GET | — | 页面（令牌注在里面，同时下 `tbx` Cookie） |
| `/页/*.js` · `/页/*.css` | GET | — | 前端那几份。**只服务 `页/` 底下的东西**，解出来的路径必须真落在里面 |
| `/toolbox/桌` | POST | `{}` | `{ 项目根, 版本, 动作表, 装不上, 模型 }`（版本来自根目录 `version.json`，不含 `V` 前缀） |
| `/toolbox/调` | POST | `{ 模块, 动作, 参数 }` | 那个动作的回执 |
| `/toolbox/模型` | POST | `{}` 看 / `{ 换:{类别,id} }` 换 | `{ ok, data }` |
| `/toolbox/链路` | POST | `{}` 读 / `{ 存:[…] }` 写 | `{ ok:true, data:{ 目录, 链路:[…] } }`（**没有密钥**） |
| `/toolbox/服务商` | POST | `{ 做什么:'列模型'\|'探图'\|'试一条', id?, 地址?, 模型?, 密钥? }` | 见 §2.4 |
| `/toolbox/任务` | POST | `{ 什么:'出图', 参数 }` | `{ ok:true, id }` |
| `/toolbox/任务/看` | POST | `{ id, 从? }` | `{ ok:true, data:{ 状态, 回执, 事件[], 共几条事件 } }` |
| `/toolbox/任务/列` | POST | `{}` | `{ ok:true, data:[…] }` |
| `/toolbox/任务/流` | GET | `?id=…&从=N` | SSE：`data: { 类型:'看一眼'\|'事件'\|'完了'\|'心跳', … }` |
| `/字节` | GET | `?存放地=&条目ID=&变体=` | 原图字节 |
| `/缩略图` | GET | `?存放地=&条目ID=&边长=` | 现缩的图（缩不出来给原图） |
| `/存图` | POST | `{ 字节, 文件名, 存放地?, 作用域?, mime?, 来源?, 显示名? }` | 图片模块 `存` 的回执 |

### 2.1 令牌

| 哪几条路 | 怎么认 |
|---|---|
| 那些 POST（桌 / 调 / 模型 / 链路 / 服务商 / 任务 / 存图 / 退出） | 请求头 `x-toolbox-token` |
| `/字节` · `/缩略图` · `/toolbox/任务/流` | 上面那条头，**或者**页面那一次响应下的 `tbx` Cookie |

**为什么图片那两条靠 Cookie**：`<img>` 发不了自定义头。Cookie 是 `HttpOnly; SameSite=Strict; Path=/`。

### 2.2 回执的拆法

与登记工具那一条相同：

| 模块给 | 这一层交回 |
|---|---|
| `{ ok:false, reason, code }` | **原样**（一个字不动） |
| `{ ok:true, data }` | 交 `data` |
| 其余（装订的 `装订` 就是这种） | 原样 |

**失败一律 200**：信封里的 `ok:false` 才是失败的说法。HTTP 状态码留给"这条路本身不对"：
`403` 令牌不对 · `404` 没这条路 · `405` 方法不对 · `400` 请求体不是 JSON · `500` 服务自己炸了。

### 2.3 缓存

绘图开关通过 `/toolbox/调` 的 `comfy/绘图开关` 动作读写：参数 `{}` 读取，`{启用:true|false}` 写入，返回 `{启用:boolean}`。缺省关闭；聊天区与设置页共用该值，界面连接状态不改变已保存的选择。出图关闭时模块返回 `COMFY_DISABLED`，手动、任务和模型调用的执行口径一致。设置写入失败时页面恢复原状态并显示失败原因。

`/字节` 与 `/缩略图` 带 `ETag` 与 `Cache-Control: private, max-age=31536000, immutable`；
`If-None-Match` 命中给 `304`。ETag 取 `"<条目ID>-<变体>-<现缩与否>-<字节数>"`——
条目 ID 是每次存图新生成的，所以同一串地址的内容不会变。

### 2.4 API 配置页那两条路

**这一层里有一样东西不是模块：服务商。** "这家有哪些模型""这个模型吃不吃图"两条都得问它本人，
所以有这两条路（"界面只调 `/toolbox/调`"说的是**模块动作**：链路表与服务商都不是模块动作）。

**`/toolbox/链路`** —— API 配置页那张表，住本机存档（见 §八）：

```jsonc
// 回的那一份（**密钥只进不出**：交出去的是"存没存过"）
{ "ok": true, "data": {
  "目录": "C:\\Users\\<你>\\AppData\\Roaming\\工具箱\\API",
  "状态": { "ok": true, "code": "", "reason": "" },
  "链路": [{
    "id": "link-1", "名字": "", "地址": "https://api.deepseek.com/v1", "模型": "deepseek-chat",
    "上下文窗口": 128000, "密钥已存": true,
    "能看图": true, "理由": "服务商收下了这张 1×1 的图", "依据": "探测"   // 依据：探测 / 声明 / ""
  }]
} }
```

链路存档确实不存在时，状态成功且链路为空；JSON、形状或 IO 读取失败时，`状态.ok` 为 false、码为 `API_STORE_READ`。理由不包含文件正文，写入拒绝覆盖读不懂的文件。API 页直接展示目录、链路条数和密钥保存状态。

```jsonc
// 写的那一份：数组的成员 = 存完还剩哪几行（不在里头的连同密钥一起删），顺序 = 优先级
{ "存": [{ "id": "link-1", "名字": "", "地址": "…", "模型": "…", "上下文窗口": 128000,
           "密钥": "sk-…",      // 只在用户现敲时出现
           "清密钥": true }] }   // 显式抹掉（只写 key:"" 会被当成"没输入"）
```

**`/toolbox/服务商`** —— 三个做法：

| `做什么` | 另外要 | 干的事 | 回 |
|---|---|---|---|
| `列模型` | `id?` `地址` `密钥?` | `GET <地址>/models`，清单连同服务商的声明记进模型表 | `{ ok:true, data:{ 地址, 取回时间, 模型:[{ 名字, 能看图, 说明 }] } }` |
| `探图` | `id?` `地址` `模型` `密钥?` | 真发一张 1×1 的图：`POST <地址>/chat/completions` | `{ ok:true, data:{ 能看图, 理由, 依据 } }` |
| `试一条` | 同上 | 发一次最小的纯文字请求 | `{ ok:true, data:{ 话说 } }` |

**`密钥` 只有两种给法**：页面现敲的那一次原样带上来（本地地址显式给空串 = 这条链路不用钥匙）；
不给就按 `id` 取这条链路存着的那把。**页面永远拿不到存下来的密钥。**

**`能看图` 是三态**：`true` / `false` / `null`（没结论）。`null` 不写进表 ——
"服务商没声明"不等于"不能看图"。`探图` 被明确拒掉才算 `false`；连不上、钥匙不对、
没这个模型都不下结论。

## 三、交付面（`/toolbox/桌`）

```jsonc
{
  "项目根": "…",
  "动作表": [
    {
      "模块": "tag",                    // 装配层给模块起的键
      "动作": "query",                  // **模块自己那层的动作名**——界面调的就是这一个
      "模型侧": "query",                // 工具注册表那套（`<模块键>_<动作名>` 的后半段，只含 ASCII）
      "摘要": "查库：给一个查询串，出一组候选",
      "参数": [
        {
          "名": "串",
          "可选": false,                // 模块写没写那个问号
          "说明": "用户敲进坢的那一段",   // 模块自己写的那句话
          "界面": { "控件": "text" },     // 或 { 控件:'select', 选项:[…] } / { 控件:'context', 字段:[{名,控件,选项?}] }
          "类型": { "type": "string" }    // 模型那一侧的类型；没编的给 null
        }
      ]
    }
  ],
  "装不上": [ { "模块": "…", "理由": "…" } ],
  "模型": { "目录": "…", "vision": […], "translation": […], "这次用": { "vision": "…", "translation": "…" } }
}
```

**`动作` 与 `模型侧` 是两套名字**：前者是模块自己那层的（`认图` `出图` 这类中文也算），
后者只给工具注册表用。**界面调动作一律用 `动作`**；`模型侧` 只用来对照与排查。

**`界面.控件` 的取值**：`text` · `textarea` · `number` · `boolean` · `select` · `ref` · `context`。

- `select` 一定带 `选项`；
- `context` 是"不给人填"的参数（引用 / 作用域 / 产出 / 识图那三个），带 `字段` 时是说这个对象里有哪些格；
- 查不到的参数：说得出的按类型推，说不出的给 `text`。

**`/toolbox/调` 两种动作名都收**：`动作`（模块侧）与 `模型侧` 都认，查不到时回
`HOST_NO_SUCH_ACTION`，理由里把这个模块交出来的动作全列出来。

## 四、面板契约

一块面板是一个工厂函数，收一份上下文，交回一个对象：

```js
// 页/面板/xxx.js
export default function 造某面板({ 宿主, 模子, 交出去, 接过来, 盯着 }) {
  return {
    名: 'xxx',                    // 与 #hash 一致
    标题: '中文标题',              // 侧栏与顶条用它
    副题: '一句话',                // 顶条那行小字
    要的模块: ['tag', 'image'],    // 缺了就如实报缺，不画一半
    画(容器, 上下文) {             // 可以交回一个"收拾"函数，切走时叫一次
      // 只做两件事：调动作、画回执
    },
  };
}
```

| # | 规矩 | 为什么 |
|---|---|---|
| 1 | 动作名、参数名、可选性、说明、控件**全部从 `宿主` 读** | 界面写第二份清单 = 规则 7 说的坏清单 |
| 2 | 回执**原样画**（失败信封也原样） | 加工过就看不到模块真正交出来什么 |
| 3 | 一切约束在界面上看得见 | 判据② |
| 4 | 不校验、不补默认值、不替模块拦 | 界面加一条，就多一个约束来源 |
| 5 | 长任务如实（没有百分比就不画） | 画一个假的比不画更坏 |

**上下文里那四样**：

| 名 | 是什么 |
|---|---|
| `宿主` | 唯一的通信口，见下 |
| `模子` | 页面里那份 `<template id="回执模子">`，给 `画回执()` 用 |
| `交出去(东西)` / `接过来()` | 面板之间递"图片的引用"那一格 |
| `盯着(说)` | 盯着那一格的变化 |

## 五、宿主接口（`页/宿主.js`）

| 方法 | 交回 |
|---|---|
| `调(模块, 动作, 参数)` | `{ 回, 耗时 }`——`回` 就是宿主给的东西，一个字不改 |
| `一条(模块, 动作)` / `参数(模块, 动作, 名)` / `参数们(模块, 动作)` / `摘要(模块, 动作)` | 交付面里那一条 |
| `图地址(引用, 变体?)` / `缩略图地址(引用, 边长?)` | 两条 GET 的地址 |
| `存图(要的)` | `{ 回, 耗时 }` |
| `换模型(类别, id)` | `{ 回, 耗时 }` |
| `起任务(什么, 参数)` / `看任务(id, 从)` / `任务流地址(id, 从)` | 任务那三条 |
| `有模块(键)` / `模块们()` / `装不上` / `项目根` / `桌` | 桌面本身 |
| `重取桌()` | 重新要一次交付面 |

**网络层失败也变成信封**：`{ ok:false, code:'PAGE_FETCH', reason:'请求没发出去：…' }`，不抛。

## 六、错误码

界面层自己发的码：

| 码 | 什么时候 |
|---|---|
| `UI_TOKEN` | 令牌不对 |
| `UI_NO_ROUTE` | 没有这条路 / 没有这个文件 |
| `UI_METHOD` | 那条路只收 POST |
| `UI_BAD_BODY` | 请求体不是 JSON（或读不动） |
| `UI_BAD_TASK` | 认不出的任务名 |
| `UI_BAD_ASK` | `/toolbox/服务商` 认不出的做法（不是 列模型 / 探图 / 试一条） |
| `UI_NO_SUCH_TASK` | 任务号指不到 |
| `UI_NO_BYTES` | 这一趟没带字节 / 回执里没有字节 |
| `UI_NO_RECEIPT` | 模块没交出回执 |
| `UI_SERVER` | 服务自己炸了（带 `栈`，便于定位） |

服务商那一面自己发的码（`对接层/界面/服务商.js`）：

| 码 | 什么时候 |
|---|---|
| `API_NO_ADDRESS` | 这条链路还没填地址 |
| `API_NO_MODEL` | 这条链路还没填模型 |
| `API_UNREACHABLE` | 连不上（网络层） |
| `API_STATUS` | 服务商回了非 2xx（`reason` 里带状态码与它自己的那句话） |
| `API_NOT_JSON` | 服务商的回应不是 JSON |
| `API_NO_MODELS` | 回应里没有模型清单 |
| `API_STORE_READ` | 链路存档 JSON、形状或 IO 读取失败；不覆盖原存档 |

页面那一侧还有两个自己发的码（`页/宿主.js`）：

| 码 | 什么时候 |
|---|---|
| `PAGE_FETCH` | 请求没发出去（网络层） |
| `PAGE_NO_SUCH_ACTION` | 交付面上没有这个 `模块/动作`——面板写错了名字，当场说清并列出这个模块交出来的动作 |
| `PAGE_NOT_JSON` | 宿主回的响应不是 JSON |

模块自己的码原样带出来（`TAG_*` / `IMAGE_*` / `PROMPT_*` / `BIND_*` / `TEXT_*` / `COMFY_*` / `VISION_*` / `PRESET_*`）。

**宿主的三个码**（`对接层/宿主.js`）：`HOST_NO_SUCH_MODULE` · `HOST_NO_SUCH_ACTION` · `HOST_BAD_KIND` / `HOST_NO_MODEL` / `HOST_MODEL_INCOMPLETE`（换本地模型那三个）。

**动作浏览器那几个码改名了**：`BROWSER_*` → `HOST_*`（模型选那一层从 `tools/动作浏览器/模型可选.js` 搬到了 `对接层/模型可选.js`）。

## 七、怎么验（自检）

```bash
node 程序/对接层/界面/试/无头.js          # 123 条
node 程序/对接层/界面/试/皮实测.js        # 117 条
```

**`无头.js`** 真起服务（真装配 · 真模块 · 真数据），把外壳与十二块面板在一个够小的假 DOM 上真画一遍。抓这些：

| 抓什么 | 怎么抓 |
|---|---|
| 语法错、名字打错、方法不存在 | 十二块面板逐个点开真跑；面板里那句"这块面板画不出来"不该出现 |
| **动作名写错** | 宿主每调一次就记进一张总账：每块面板画完对一遍交付面，再点三个按钮对一遍 |
| 面板契约破了 | 导航九项齐；交付面上每条动作都带齐 模块/动作/模型侧/摘要/参数/控件 |
| 令牌与越界 | 不带令牌取字节被挡 · 页面那条路走不出页目录 · 没这条路就 404 |
| 端到端 | 真造一张 PNG → 清空那一格 → `/存图` 落进识图工作区（写完仍是 1 张）→ `认图` 打出真标签 → 删干净 |
| 那三个按钮 | 先种一张图进识图工作区 → 面板自己把它挑上 → 认图 / 读元数据 / 看图 逐个点，三个都真调到模块 |

**它不断言长相**：长得对不对只能人看。

**`皮实测.js`** 起真服务 + 真浏览器（CDP），验的是"旧版那层皮接上我们的模块之后还通不通"（117 条）。
API 页那 27 条落在**一个假服务商**上：`试/皮实测.js` 现起一个本地 HTTP（`/v1/models` 交四个模型、
`/v1/chat/completions` 对带图的请求分两种回答），于是"取清单 · 探测 · 测试连接"三条都真走一遍，
不需要真 key、也不碰用户那份存档（自检自己造一个临时 `--数据目录`，跑完删净）。

## 八、盘的形状

模块数据由各模块存储。应用存档还包括 API 配置页的链路与模型表，以及会话模块的单会话文件；当前选择属于页面 preferences。

| 谁的数据 | 住哪 |
|---|---|
| 图 | `工具箱数据/图片/`（图片模块的根目录） |
| 世界书 | `工具箱数据/世界书/世界书.json` + `世界书模块/assets/世界书/` |
| 预设 | `工具箱数据/主AI/预设.json` + `主AI模块/assets/预设/` |
| comfyUI 工作流 | `工具箱数据/comfyUI/工作流.json` |
| 配置 | `对接层/cordis.patch.yml`（**界面只读它**） |
| **链路表 · 模型表** | **`%APPDATA%\工具箱\API\`**（C 盘用户目录底下，**不在软件目录里**；`--数据目录` 可换） |

两份文件（形状与字段见 §2.4 与 `对接层/界面/服务商.js` 的文件头）：

| 文件 | 装什么 | 谁写 |
|---|---|---|
| `链路.json` | 用户填的：地址 · 模型 · 上下文窗口 · **密钥（明文）** | 页面（`/toolbox/链路`） |
| `模型表.json` | 问回来的：这家提供哪些模型、各自声明了什么；每个（地址 · 模型）的图片能力结论 | 服务商那一面 |

**"密钥明文写在 C 盘那份文件里"是页面上一句话说清了的事**（`#linkStorePath` 写着真路径），
不是藏起来的实现细节：本机个人项目，不加系统安全存储那一层。

## V1.5.1 独立助手与提示词

`POST /toolbox/调` 的 `模块:session` 接收会话唯一动作表；动作、字段和端口见 [会话接口](../../会话模块/接口.md)。成功回执由宿主解包 data，失败保留信封。`GET /对话/流` 仅传 `{实例,版本,变更,已删}`；读列表与当前详情分别比较版本，并检查实例和选择代次。

会话文件在 `工具箱数据/会话/<会话ID>.json`；草稿按会话保存，纯图有效，运行中同目标发送返回 SESSION_BUSY。停止只是请求，页面显示停止中直到收口。素材走 image/存 与原图片门面；历史及草稿保留缺图引用。格式说明从会话 describe 读取。归档为自包含 `.toolbox-session.json`，保图删除、部分失败与重试保存按会话接口执行。

提示词页不另设写入路由；模型工具设置、世界书条目和启用列表全部走 `/toolbox/调` 与模块自己的 `存`。设置导入导出只包含主 AI 的模型和工具配置。默认书只读，复制后可编辑。主 AI 与其他请求统一使用世界书订阅；启用书不受默认设置只读影响。运行和发送预览都调用世界书 `执行({请求,文本})`，不传设置引用覆盖列表。
