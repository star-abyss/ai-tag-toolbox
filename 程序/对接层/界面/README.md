2026-10-18 修复：ComfyUI 连接、开关和工作流均就绪时，手动刷新显示“已连接 · 工作流已就绪”；输入草稿引发同内容快照更新时，聊天按消息段保留已有图片节点。回归为 `试/绘图开关.js`、`试/聊天呈现.js --图片复用` 与完整 `试/聊天呈现.js`，均通过。当前桌面运行版已更新两份界面脚本，真实 ComfyUI 与原工作流刷新验证通过，未提交新的出图任务。

**它是什么**：一个本地 HTTP 服务加一个浏览器页面。九个模块的动作在界面上点得着、看得见回执。
**住哪**：`对接层/界面/`，与调试台（`对接层/tools/动作浏览器/`）平级。
**零构建**：原生 ES module + 一个 CSS，`node` 起了就能用。

翻译页直接消费模块回执中的原文/译文范围，双向悬停、选区和复制使用同一结果。普通句子按整句或短语对应；混合内容按语言片段翻译并保留已有目标文字。自动翻译为 500 ms 防抖加一次在飞、一个最新待处理输入；失败有重试入口，页面不缓存译文。

翻译专项验证（仓库根运行）：`node 程序/对接层/界面/试/翻译工作区.cjs`、`node 程序/对接层/界面/试/翻译链路.js`、`node 程序/对接层/界面/试/翻译浏览器.js`。后两项使用真实本地模型；浏览器测试另用隔离服务商验证 AI 装订。浏览器脚本可追加实际运行页面 URL，复验交付副本。

## 一、怎么起

```bash
node 程序/对接层/界面/服务.js
```

打开控制台打出来的那个地址（默认 `http://127.0.0.1:8790/`）。换端口 / 指项目根 / 换存档目录：

```bash
node 程序/对接层/界面/服务.js --端口 8800 --项目根 <程序目录> --数据目录 <另一处> --开
```

双击根目录的 `启动.cmd` 会打开一个 Windows 控制台并在前台运行 Node 服务。服务准备并监听本机端口后，自动打开系统浏览器。程序随控制台运行；关闭控制台后服务退出。端口被占用或启动失败时，原因显示在控制台，按键后关闭窗口。

启动和服务输出显示在控制台。Windows 入口真实进程验收：`powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/test-run.ps1`。

上述命令从仓库根目录运行。`--项目根` 指包含各模块、模型与存档的 `程序/` 目录，默认由服务文件的位置确定。根目录 `启动.cmd` 是唯一运行入口；服务由 `程序/对接层/界面/服务.js` 前台承载。

**要令牌**：令牌每次启动现生成，注在页面里，同时下一个 Cookie（`<img>` 那两条路靠它）。

**存档**：API 配置页填的链路与"问回来的模型表"住 `%APPDATA%\工具箱\API\`（C 盘用户目录底下，
`--数据目录` 可换）。服务直接运行时会在控制台显示存档位置。

对话记录住当前版本的 `程序/工具箱数据/会话/`，会话图片住 `程序/工具箱数据/图片/session/`，ComfyUI 工作流住 `程序/工具箱数据/comfyUI/工作流.json`。ComfyUI 服务地址由 `程序/对接层/cordis.patch.yml` 的 `comfyUI地址` 配置。`--数据目录` 只改变 API 存档位置；切换软件文件夹会读那个文件夹自己的会话和工作流，打包脚本不携带 `工具箱数据/`。跨版本带走对话可在对话管理中导出、导入自包含会话归档。
API 页的状态行显示已读到的配置条数与已保存 Key 条数；存档文件缺失代表空配置，读取失败会显示错误并停用新增，避免把损坏文件当空表写回。

聊天区和 ComfyUI 设置页的「启用绘图」共用模块持久化的开关，缺省关闭，离线也可切换。关闭后新出图请求返回 `COMFY_DISABLED`；已提交任务继续运行。导入或清除工作流保持开关选择。回归：`node 程序/对接层/界面/试/绘图开关.js`，使用隔离服务与真实浏览器，不触发真实出图。

### 2.1 旧版那层皮

`/` 上现在跑的是**旧版 V1.5.65 那一整层界面**（`index.html` + 16 份 CSS + 28 个脚本 +
`views/*` + `locales/*` + `assets/icons/`），底下接我们的模块；V1.5.1 的提示词编辑器已按新设计重写。

| 文件 | 管什么 |
|---|---|
| `页/index.html` | 旧版的骨架。**它才是 `/` 上那一页** |
| `页/app.js` · `页/app-view.js` · `页/views/*` · `页/dsh-*.js` | 旧版的视图层，原样搬来 |
| `页/app.css` · `页/workspace-theme.css` · `页/dsh-*.css` … | 旧版的样式，原样搬来 |
| `页/locales/zh-CN.json` · `en-US.json` | 旧版的语言包。界面上 `data-i18n` 那些字全靠它 |
| `页/我们的模块.js` | **我们这一层**：造 `window.AppModules`，接到 `/toolbox/调` |
| `页/我们的令牌.js` | 令牌走同源脚本（旧版那份 CSP 是 `script-src 'self'`，内联会被拦） |
| `页/我们的页.html` | 我们原来那份十二块面板的页面，**留着对照**，地址 `/页/我们的页.html` |

**为什么这样搬得动**：旧版的界面与后端之间本来就只有一道缝 —— `app.js` 开篇一句
`global.AppModules`。视图是依赖注入的工厂，所以把那一袋东西换掉，界面一行不用动。

**一处必须知道的取舍**：旧版有一批方法是**同步读**的（`tags.page` · `catalog.getTag` ·
`favorites.list` …，因为它的标签库抱在内存里）。我们这一侧只有 HTTP。所以适配层开了
一条**同步通道**（同步 XHR，本机往返约 1 毫秒），再加记录缓存与分类树缓存。
**代价**：`tag/record.groups` 那种 4.6 MB / 3 秒的回执不能走同步通道，得后台加载。

**启动取数**：分类成员由 `render.pageMap` 每页取一次，同一份结果填入页与类的成员缓存；首屏只取显示的 400 条记录。角色记录在首次进入角色库时异步分批取，页面显示加载状态，完成后自动画出卡片。作品分组复用成员缓存，遍历一次建立。

**服务那一侧的装配在上一层**：[../宿主.js](../宿主.js)（读配置 · 装八个模块 · 交桌面）与
[../模型可选.js](../模型可选.js)（本地模型那一格）。调试台走的是同一份。

**那一层皮里我们真接上的一块：API 配置页**（AI 页 → API 页）。它填的链路（地址 · Key · 模型 ·
上下文窗口）住本机存档，模型那一格点一下就现去服务商那边取清单，"这个模型能不能看图"
要么读服务商的声明、要么真发一张 1×1 的图问它。契约在 [接口.md](接口.md) §2.4，
这一面的实现在 [服务商.js](服务商.js)，设计与三条决定在 [../../界面设计.md](../../../文档/界面设计.md) §六。

## 三、怎么调

### 起服务、看桌面

```bash
node 程序/对接层/界面/服务.js
# 另开一个终端：
curl -s -X POST http://127.0.0.1:8790/toolbox/桌 -H "x-toolbox-token: <控制台那份>" -H "Content-Type: application/json" -d "{}"
```

### 从 HTTP 调一个动作

```bash
curl -s -X POST http://127.0.0.1:8790/toolbox/调 \
  -H "x-toolbox-token: <令牌>" -H "Content-Type: application/json" \
  -d '{"模块":"tag","动作":"query","参数":{"串":"miku","上限":3}}'
```

### 自检

```bash
node 程序/对接层/界面/试/无头.js          # 125 条：假 DOM，我们那份十二块面板
node 程序/对接层/界面/试/皮实测.js        # 121 条：真浏览器（CDP），完整界面 + API 页 + 提示词页
node 程序/对接层/界面/试/皮实测.js --启动 # 只验启动取数、分类计数、角色库按需加载与分页
node 程序/对接层/界面/试/识图界面.js      # 真浏览器：上传自动提取、本地打标、结果保留、缺模型回执
node 程序/对接层/界面/试/识图界面.js --外观 # 另存首页、识图、助手、档案页的浅色/深色/窄窗截图
node 程序/对接层/界面/试/提示词列表.js    # 提示词折叠编辑、世界书搜索与行内启停、未保存正文保留
node 程序/对接层/界面/试/基础提示词.js    # 真实宿主与隔离服务商：基础提示词进入副请求及识图 JSON 解析
node 程序/对接层/界面/试/世界书工作区.js  # 编辑A、启用B；顶部真实启用、脏正文保留与刷新读回
node 程序/对接层/界面/试/消息编辑.js    # 用户/AI 正文编辑、逐轮重新生成入口与运行态禁用
```

提示词页采用酒馆式通栏布局：顶部多选标签框显示实际启用书，右侧折叠区选择要调整的请求；点「＋」勾选，标签上的「×」移除。下面一行独立选择编辑对象与世界书管理图标，再往下是搜索与紧凑条目列表。初始打开文生图基础书，预设与工具编辑可从编辑选择器或右侧折叠区进入。翻译、识图、文生图默认各启用对应基础书，主动停用后保留选择；编辑和启用始终独立。

两份各管一边：`无头.js` 拿假 DOM 画我们自己的页面，**验不到长相**；
`皮实测.js` 起真 Edge、真点按钮，**每一条判据都拿页面上的数与直接调 `/toolbox/调` 的结果对账**
（侧栏计数、卡片、搜索候选、选中、译文），跑完还会把当前那一屏截到 `临时/截图/皮-最新.png`。

启动回归同时检查：每个分类页只取一次成员、不逐类发同步请求、首屏只缓存 400 条记录、角色库在进入前不加载记录、首次进入后自动显示卡片。

首页与对话档案的样式在 `页/workspace-refresh.css`。档案页和助手侧栏使用同一个对话列表组件；档案页打开时只显示档案列表。识图上传后的内置提示词通过装订动作切分，本地打标和元数据结果随当前图片保留；失败回执显示在识图面板。桌面运行离线识图需要模型，交付时使用 `scripts/打包.ps1 -IncludeModels`。

**API 页那 27 条落在一个假服务商上**：`皮实测.js` 自己起一个本地 HTTP（`/v1/models` 交四个模型、
`/v1/chat/completions` 对带图的请求一个收下一个拒掉），存档指向一个临时目录（跑完删）。
所以"取清单 · 探测 · 测试连接"三条都真走一遍，不需要真 key。

## 四、加一块面板

1. 写 `页/面板/<名字>.js`：交一个工厂函数，收 `{ 宿主, 模子, 交出去, 接过来, 盯着 }`，
   交回 `{ 名, 标题, 副题, 要的模块, 画(容器, 上下文) }`。
2. 在 `页/壳.js` 顶上的 import 与 `工厂们` 里各加一行。
3. 跑 `node 试/无头.js`：导航会多一项，自检会把新面板也真画一遍。

**面板里只准做两件事**：调动作、画回执。参数名与控件从 `宿主.参数(模块, 动作, 名)` 拿——
拿不到就说明宿主没交这一条，**不要去猜**。

**长相只从模板里取**：按钮、输入、卡片、分段、浮层用哪几个类名，看 [组件.md](组件.md)。
面板里临时捏一个类名，自检会当场报出来（第十二节那条）。

## 五、哪条不能动

| # | 规矩 | 为什么 |
|---|---|---|
| 1 | **面板不认识任何模块的内部结构**：动作名、参数、说明、控件全部来自宿主 | 界面写第二份清单 = 规则 7 说的坏清单 |
| 2 | **面板不直接 `fetch`**，只走 `页/宿主.js` | 将来搬进别的壳，换的只是那一个文件 |
| 3 | **回执原样画**，不加工、不改字段名 | 加工过就看不到模块真正交出来什么 |
| 4 | **不校验、不补默认值、不替模块拦** | 界面加一条就多一个约束来源；拒绝是模块的事 |
| 5 | **参数值的读法只有一条**，且只对对象形状生效 | 界面不去猜类型，猜错了就是"界面替用户决定事情" |
| 6 | **JSON 里不带图**：字节走 `/字节` 与 `/缩略图` | 一张 1.2 MB 的 PNG 过 JSON 要变约 160 万字符 |
| 7 | **缩略图不落盘** | 盘上一份就是第二份真相；条目自己那一档有就用它 |
| 8 | **`服务.js` 被 import 时不许起服务** | 自检与诊断脚本会 import 它；起了就占端口、装两次模型 |
| 9 | **`装订 / 切分` 与 `有内容的格` 一起用** | 契约这么定的；界面不写第二套"这一格有没有内容" |
| 10 | **不画进度条** | 模块只报状态切换，没有百分比 |
| 11 | **API 配置页那两条路不是模块动作**：链路表（界面自己那份配置）与服务商（"有哪些模型""吃不吃图"）各有自己那一条 | 它们不是哪个模块交出来的东西，硬塞进 `/toolbox/调` 就得凭空造一个模块出来 |
| 12 | **密钥只进不出**：页面永远拿不到存下来的密钥，只拿得到"存没存过" | 拿得到就等于把密钥摊在页面上 |
| 13 | **"能不能看图"只由服务商回答**，不许拿模型名猜 | 名字不是证据；猜错的代价是识图静悄悄走错链路 |

## 七、症状 → 位置

| 现象 | 先看 |
|---|---|
| 页面打不开 / 白屏 | 控制台那份启动输出；`页/壳.js` 的 `起()`（它在最前面要动作表） |
| 选了 tag，底栏只有一个空条：没名字、预览空、卡片上也没有选中态 | `页/我们的模块.js` 的 `翻选中()` —— 旧版要的是 `{key, kind, tagIds, content, displayName}`，少了 `tagIds` 会在 `combinedSelectionText()` 上抛异常，底栏就停在那儿 |

| 角色库只有四千多个、作品名几乎全是"（没写作品）" | `tag模块/data/表/角色.json` 装错了表（[tag 模块设计决定 118](../../tag模块/标签模块设计.md)）；现行口径见 [界面设计.md](../../../文档/界面设计.md) 决定 37 |
| 标签组里冒出三万个组 | `我们的模块.js` 的 `searchGroups()` 过滤：只留两张身份表都不认的（用户自己建的） |
| 每一条请求都 403 | 令牌没注进去：`配置.js` 的 `注令牌` 与页面里那个标记 |
| 图库一片空白、原图也画不出来 | `/字节` 与 `/缩略图` 的报错（它们在响应体里给码，不是 HTTP 状态） |
| 缩略图很大、加载慢 | `sharp` 装没装（`对接层/node_modules`）；装不上会照原样给原图 |
| 出图点了没反应 | 任务那条路：控制台那份令牌是对的？看 `POST /toolbox/任务` 的回 |
| 某块面板说"要的模块没装上" | 顶部那句里带着宿主的理由；去 `对接层/cordis.patch.yml` 对位置 |
| 面板画到一半不动了 | 它等的那个动作；去"全部动作"那块用同样的参数调一次看回执 |
| 世界书改了不生效 | **这是对的**：`执行` 读存档、`测` 读草稿。界面上那个"草稿改过，还没存"就是它 |
| 换了模型没变化 | 模型条那次响应的回；换不了时它不动现在用的那一格 |
| API 配置页填了存不住 | `/toolbox/链路` 的回；启动那一行打出来的存档目录写不写得进去 |
| 模型那一格点开没有候选 | `/toolbox/服务商 {做什么:'列模型'}` 回的那句话（连不上 / 钥匙不对 / 这个地址没有模型清单）——它就在那一格下面写着 |
| 徽标一直是 `👁?` | 服务商没声明、探测也没结论。点「👁 探测」看它回什么；结论按（地址 + 模型）进 `模型表.json` |
| 填了模型却探测不成 | 探测按 `id` 取这条链路存着的钥匙：先确认这一行存过了（输入框失焦即存） |

## 八、跟调试台什么关系

| 谁 | 走哪条路 | 留着干什么 |
|---|---|---|
| `tools/动作浏览器/` | 浏览器 → HTTP → 宿主 → 门面 | 某块面板还没做，从这儿先用；某块做坏了，从这儿对照看原始回执 |
| **本层** | 同上，多一层面板 | 按用途画好的界面 |

**两份服务共用装配**（`对接层/宿主.js` 与 `对接层/模型可选.js`），所以"装了什么、缺什么"两处说法一致。

## V1.5.1 助手与提示词

双击启动即可使用助手，无需另启 DSH 对话桥。API 沿用现有配置。[会话模块](../../会话模块/README.md) 保存单会话记录、轮次和草稿；宿主配置 `会话目录` 唯一决定会话文件位置。当前选择由页面 preferences 保存。执行器 `对接层/会话执行.js` 每轮固定主 AI、世界书和模型设置，工具声明与实际回执经同一门面逐步保存；支持停止、纯图发送和缺图显示。

提示词页的预设入口保留身份与流程、模型、工具、程序附加、发送预览各段，查看预设不切换使用。顶部主 AI 世界书操作始终写实际使用预设，未生效的查看对象不受影响。默认内容只读，复制或新增后可编辑。世界书条目行可直接改标题、触发方式、插入位置、深度和角色；选项从宿主读，局部保存不替换正文编辑器。关键词 JSON 仅编辑 keys。主 AI 的世界书引用存预设，其他请求的启用列表存世界书模块；完整预设导出可原样导回。

工具卡按模块动作的用途显示，可搜索名称、用途和参数；用户预设保存工具快照，默认工具表按模块动作实时计算。`对接层/工具定义.js` 是运行登记与界面预览共用的转换，最终发送的工具说明、参数 Schema 和 required 数组可在预览 JSON 中查看。程序附加页显示会话格式说明；发送预览把身份、流程、命中世界书、会话格式与当前素材标识拼成完整系统消息。浏览器回归逐字核对系统消息，并将完整 tools 与本地 HTTP 服务实际收到的内容对账。

主聊天固定使用「主AI」请求。切换查看文生图、识图或翻译，仅配置该副请求的模型与世界书；副请求不使用主 AI 的身份、流程与工具，页面不显示这些无效字段。世界书的前、后进入系统消息，按深度作为 user 内容追加，其余落点仍不装配，预览说明会标出。

新增回归：`node 程序/对接层/界面/试/AI对话.js`、`node 程序/对接层/界面/试/AI页.js`。

API 存档回归：`node 程序/对接层/界面/试/API存档.js`。缺失文件是空配置；JSON、格式或 IO 读取失败明确显示 `API_STORE_READ`，不覆盖原文，模型请求也保留该错误。

ComfyUI 导入 PNG 时，字节经 `vision/读元数据` 解析，再经 `comfy/存工作流` 保存；不暂存到图库，不改变图库或待回收目录。真实样例回归：`node 程序/对接层/界面/试/识图界面.js --workflow-only <含工作流的PNG>`。

对话管理回归：`node 程序/会话模块/test/run.js`、`node 程序/对接层/界面/试/对话管理.js`。侧栏平铺所有会话，显示标题、消息数和运行状态；侧栏与聊天区各只有一套渲染器。支持新建、切换、改名、删除、清空、导入导出，刷新恢复当前会话。

会话管理动作统一经 `/toolbox/调`；`GET /对话/流` 只通知实例、版本与变化 ID。归档下载为 `.toolbox-session.json`，包含所有现存会话素材，导入重建活动 ID；删除的保留图片选项先复制到图库。旧本机存档不读取迁移、不删除。
