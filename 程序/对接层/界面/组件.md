# 界面组件模板

> **这份是界面里的"零件清单"**：界面上所有控件分几类、每类叫什么、长什么样、什么场合用哪个。
> 面板 JS 只准用这里面的类名；要加新零件，先加到这一份里，再写实现（`页/组件.css`）。
>
> **读者**：写面板的人，以及要改界面长相的人。
> **不含**：路由与面板契约（看 [接口.md](接口.md)）· 为什么界面住在这一层（看 [../../界面设计.md](../../../文档/界面设计.md)）。

---

## 一、为什么要这一份

现状是**每个面板各写各的**：立这一份之前，九块面板一共造出 118 个控件点，同一个意思在不同面板里是三种写法。

实测（立这一份之前那九块的存量）：

| 现象 | 数 |
|---|---|
| `造('select', { style: { width: 'auto' } })` 这一句在 7 处各抄了一遍 | 7 |
| "搜索框 + 防抖 + 按 Enter 查"这套在标签面板写了，别的面板要写就再写一遍 | 1 处实现 |
| 按钮有 `.主` / `.危` / `.小钮` 三个修饰类，但没有"这几个是一组"的写法 | 3 |
| 提示语有 `alert` 8 处 · `confirm` 5 处 · `prompt` 2 处 | 15 |
| 列表有 `.清单`、网格有 `.格子们`，别的面板要展示卡片只能二选一凑 | 2 |

**结果**：改一个控件要翻九个文件；同一个词（"重列"、"体检"、"看模型"）在每个面板里长相都不一样。

这一份定的就是：**控件先分类，每类一个类名，面板只管用。**

**现在什么状态**：十二块面板都已经按这一份换过一遍，`页/组件.css` 里**没有遗留的旧类名**
（迁移期那一节已删）。自检第十三节会挡着新加的自造类名。

## 二、令牌

颜色与尺寸都由 `:root` 上的变量给（在 `页/页.css` 里）。**面板与组件不许写死颜色**，这条照旧。

### 2.1 颜色

| 变量 | 用途 |
|---|---|
| `--底` `--板` `--板硬` `--点亮` `--浮` | 五级表面，从页面底到浮起来的那一层 |
| `--线` `--线亮` | 描边（普通 / 需要看清的那条）。**半透明白**，压在任意一档表面上都成立 |
| `--字` `--字淡` `--字更淡` | 三级文字 |
| `--主` `--成` `--错` `--警` | 品牌色与三种状态 |
| `--主亮` `--成字` `--错字` `--警字` | 压在上面那几档**淡底**上的文字色 |
| `--主bg` `--成bg` `--错bg` `--警bg` | 上面四色对应的**底色**版本（淡色块） |
| `--主线` `--成线` `--错线` `--警线` | 淡色块那一档的描边 |
| `--主字` | **压在实心主色上的**前景色（就是白）。`.钮.主` 用它 |

**规矩**：一块淡色底（`.标签`、`.提示`）永远配它那一档的文字色，不许拿 `--成` 当文字色压在 `--成bg` 上。
`--主` 那一档特殊：`--主字` 是给**实心**主色钮用的白字，淡底上的主色文字要用 `--主亮`（`.标签.主` 就是这条）。

### 2.2 尺寸

| 变量 | 值 | 说明 |
|---|---|---|
| `--圆` | 7px | 控件圆角 |
| `--圆大` | 12px | 卡片、块、对话框 |
| `--行` | 28px | 普通控件高度 |
| `--行小` | 22px | 小钮、标签 |
| `--行大` | 34px | 搜索框 |
| `--侧栏宽` | 212px | 外壳侧栏 |
| `--标` | 16px | 图标边长（导航项、搜索框的放大镜） |

**间距固定用这五档**：4 · 6 · 8 · 12 · 16（px）。面板里出现的别的数就是特例，特例要写成行内 `style` 并说明为什么。

### 2.3 进深

界面靠三样东西把"一块东西"与"一片背景"分开，不靠底色差：

| 变量 | 值 | 用在哪 |
|---|---|---|
| `--影1` | 一层贴地的细影 | 卡片、块、顶条 |
| `--影2` | 抬起来一档 | 卡片 hover |
| `--浮影` | 浮层 | 对话框、吐司 |
| `--内凹` | 一条内阴影 | 输入框、搜索框、分段底 |

另外 `body::before` 铺了两团极淡的径向渐变（左下偏主色、右上偏青色），页面因此有环境光而不是一整块死黑。

### 2.4 动效

| 变量 | 值 |
|---|---|
| `--快` | .13s（hover / 状态切换） |
| `--慢` | .26s（浮层进出） |

`prefers-reduced-motion: reduce` 时两者都归零。

### 2.5 图标

**图标是 CSS 遮罩，不是元素。** `--图-<名>` 里放一条 data URI，用它的地方写：

```css
-webkit-mask: var(--图-tag) center / contain no-repeat;
mask: var(--图-tag) center / contain no-repeat;
background: currentColor;   /* 图标跟着字色走 */
```

**为什么走遮罩**：遮罩吃 `currentColor`，图标自动跟着字色/选中态变；
而且不用在 JS 里造 SVG——`页/试/假DOM.js` 那份替身只认 `document.createElement`，
`createElement('svg')` 出来的元素在真浏览器里也不成图形。

| 在哪 | 怎么挂 |
|---|---|
| 侧栏十二项 | `.导航项[data-面板="<键>"]::before`（键就是面板的 `名`） |
| 搜索框 | `.搜框 .镜`——里面那个 `⌕` 字形用 `font-size: 0` 让位，位置给遮罩 |
| 顶条「重读动作表」 | `#重读::before` |

图形取自 Lucide（ISC 许可，原文在 `页/图标许可.txt`）。要加图标：
在 `页/试/造图标.js` 的名单里加一条 → 跑一次 → 把输出贴回 `页/页.css` 的 `--图-*` 那一段。

## 三、零件清单

命名沿用仓库既有的中文词：**类名说"这是什么"，不夹状态**。状态一律走 `data-*` 或修饰类。

### 3.1 按钮

| 类名 | 长相 | 什么场合 | 例子 |
|---|---|---|---|
| `.钮` | 普通灰钮 | 大多数动作 | 重列 · 体检 · 看模型 |
| `.钮.主` | 实心品牌色 | **一块面板只给一个**：这块最想让人按的那个 | 出图 · 上传图 · 存 |
| `.钮.危` | 红字红边 | 不可逆、会删东西 | 清空 · 删这一套 · 删这本 |
| `.钮.小` | 小一号 | 列表行里、卡片角上 | 取图 · 存进图库 · 改 |
| `.钮.幽灵` | 无边框，hover 才显 | 一排里次要的那些、图标钮 | ↑ ↓ · 折 · 拷 |
| `.钮[disabled]` | 半透明 + 禁点 | 跑着的时候 | 一个动作钮自己会加 |

**成组**：`.钮组`（`display:flex; gap:6px`）——一行里有好几个同级动作时用它，不要用 `.横排` 凑。

**规矩**：
- **一块面板的主操作钮不超过一个**。两个实心钮就等于没有重点。
- 一排超过 4 个钮就用 `.钮.幽灵` 或收进 `.钮组`，别把实心钮排成一行。
- 动作钮一律走 `一个动作钮()`（`顺手.js`）：它管"跑着…"、耗时、`finally` 里恢复禁用。**面板不要自己写这套。**

### 3.2 输入

| 类名 / 造法 | 用途 | 谁用 |
|---|---|---|
| `造('input', { type: 'text' })` | 一行字 | 名字、ID、路径 |
| `造('input', { type: 'search' })` | 搜索词 | 查库 |
| `造('textarea', { rows: n })` | 多行字 | 提示词、注释、JSON |
| `造('input', { type: 'number' })` | 数 | 上限、阈值 |
| `.搜框` | 搜索框外壳（放大镜位 + 可选的 `.清` 钮） | 顶条 |

**规矩**：
- **不写 `style` 调宽高**。要窄用 `.字段.窄`，要宽用 `.字段.宽`，要占满用 `.字段.满`。
- 输入框永远包在 `.字段` 里：`.标`（名字 + `.可选` + `.标签`）+ `.说`（那句说明）+ 控件。
- **不给校验、不给默认值、不给必填**（判据②）。留空就是不传。
- 控件由交付面决定，面板不挑控件：一律走 `画一个参数()`（`顺手.js`）。

### 3.3 选择

| 类名 | 用途 |
|---|---|
| `造('select')` | 单选。**默认占满宽度**；要按内容宽就用 `.选.窄` |
| `.分段` > `.段` | 2–5 个互斥视图之间切（标签墙 / 查库 / 位置 / 隐藏库） |
| `造('input', { type: 'checkbox' })` + `.标` | 开关一档（启用 / 只读） |

**规矩**：
- **互斥视图用 `.分段`，不用 `<select>`**。下拉里藏着三个页签，用户看不见有别的页；分段摆在那儿一眼看得见。
- 下拉只用在"选项是数据给的"场合（位置、存放地、模型）。
- `.段[aria-selected="true"]` 是选中态——**用 aria 属性，不用类**，读屏与样式同一个来源。

### 3.4 显示

| 类名 | 用途 |
|---|---|
| `.标签` + `.成`/`.错`/`.警`/`.主` | 小圆角片：状态、计数、`#ID` |
| `.提示` + `.淡`/`警`/`错`/`成` | 一整条横贯的说明 |
| `.细节` > `dl` | 键值对 |
| `.表` | 真正的表格（列要对齐时） |
| `.卡片们` > `.卡片` | **卡片网格**：标签墙、图库、产出列表共用 |
| `.清单` > `.清单项` | **纵向列表**：搜索结果、任务列表、条目列表共用 |
| `.条` | 一行，中间用 `.伸` 顶开 |
| `.栏头` | 一栏的小标题 + 右侧计数 |
| `.空` / `.等` | 空态那句话 / 读取中 |
| `.装填` | 一块正在读的占位（灰块 + "读着…"） |
| `.说.码` | 等宽小字：ID、码、字节数、耗时 |

**卡片与清单怎么选**：东西**有名字、要扫一眼看很多个**（标签、图）→ `.卡片们`；东西**有前后顺序、要逐条读**（回执、任务、条目）→ `.清单`。

### 3.5 浮层

| 类名 | 用途 |
|---|---|
| `<dialog class="对框">` | 要人填完了才能继续（改这一条、新建一本） |
| `.对框头` / `.对框身` / `.对框脚` | 三段 |
| `.吐司` | 一句反馈，1.2 秒后自己走（换模型失败、存取失败） |

**`alert` / `confirm` / `prompt` 一律不用**（现存 15 处逐步换掉）：

| 原来 | 换成 |
|---|---|
| `alert('存不上：…')` | `.吐司.错`，或者画进这一块的 `.提示.错` |
| `confirm('删掉？')` | `.对框` 里两个钮，危钮在右 |
| `prompt('新名字', 旧)` | `.对框` 里一个 `.字段` |

**为什么**：这三个东西会遮住整页、在假 DOM 里是空壳（自检走不到）、也没法在一条流程里连起来。

**拦阻画在面板里，不弹窗**（判据②的正面写法）：

| 场合 | 写法 |
|---|---|
| 缺前置（"先挑一张图"） | **面板里一行 `.提示.警`**，不是弹窗 |
| 操作失败 | **`画回执()` 原样画**，不是弹窗 |
| 操作成功但没声 | `.吐司.成`（可省） |

### 3.6 布局

| 类名 | 用途 |
|---|---|
| `.横排` / `.竖排` | flex 容器（`gap: 8px`） |
| `.伸` | flex 撑开的那一格 |
| `.块` | 一块带框的内容区 |
| `.两栏` | 左边一列 + 右边详情（默认 300px，`.宽左` 400px） |
| `.墙` | 面板自己的三段：顶条 / 身子（可滚）/ 底栏 |

**滚动只给一处**：一块面板里最多一个滚动容器（通常是身子那一段）。别在卡片里再嵌一个滚动。

## 四、一条硬规矩：面板不自造类名

**面板 JS 里出现的类名，只能是这一份里列过的。**

理由与本层另外两条同源：类是"长相的唯一来源"（住在 `页/页.css` 与 `页/组件.css`），
面板是"用它的地方"。面板里临时捏一个 `.我的特殊卡片`，就等于把长相拆成了十二份，
下一个人改样式时要先 grep 九个文件才知道谁在用。

**要新零件怎么办**：在这一份的第三节加一行 → 在 `页/组件.css` 里写 → 面板才用。
三步都走完才算加进去了。

**例外只有两条**：
1. 面板自己的**根容器**可以带一个 `.面板-<名>`（供将来定位用，目前没人读）；
2. `.提示` 这类带语义修饰的（`.提示.错`）可以按第三节的表组合。

## 五、验收

模板是样式，自检**罩不住它**（假 DOM 没有 CSS 解析、没有 `getComputedStyle`）。所以判据是两条：

| 判据 | 怎么查 |
|---|---|
| 面板里没有自造类名 | `node 程序/对接层/界面/试/无头.js` 里的"类名都在模板里"那一条（源码级扫 `造()` 的类名，对 `组件.css` 的选择器表） |
| 长得对不对 | **只能人看**。跑起服务打开页面，十二块面板逐个过一眼 |

第二条没有替代品，别指望自检报长相。
