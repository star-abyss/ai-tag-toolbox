# 界面布局

> **这份定"一块面板长什么样"**：有哪几种版式 · 每块面板用哪一种 · 八个公共区各放什么 ·
> 十二块面板怎么排。
>
> 零件（按钮 / 输入 / 卡片 / 分段那些类名）在 [组件.md](组件.md)；契约（路由 · 交付面 ·
> 面板接口）在 [接口.md](接口.md)；为什么界面住在这一层在 [../../界面设计.md](../../../文档/界面设计.md)。

---

## 一、从哪来的

照着旧版六张截图（标签选择器 · 角色库 · 翻译 · 识图 · 对话 · 收藏栏）抽出来的。

**只抽结构，不抄长相**：旧版那些页里，真正反复出现的只有三件事——

1. **一条顶栏**：标题在左、动作在右，下面一行搜索或筛选项；
2. **一条底栏**：左边说"现在选了几个"，右边几个动作；
3. **身子中间二选一**：要么"左边一列、右边一片"，要么"一格一格铺开"。

剩下的全是各页自己发挥。所以这一份只定这三件事 + 八个公共区，别的交给面板。

## 二、三个公共区

每一块面板的身子都是这三段，**顺序固定、位置固定**：

```
┌─────────────────────────────────────────────────┐
│ ① 顶栏   标题 · 副题 · 主操作          [定]      │  ← 不滚
├─────────────────────────────────────────────────┤
│ ② 工具条 视图切换 · 搜索 · 筛选        [选]      │  ← 不滚；没有就不画
├─────────────────────────────────────────────────┤
│                                                 │
│ ③ 身子   内容                        [滚]      │  ← **全页唯一滚动的地方**
│                                                 │
├─────────────────────────────────────────────────┤
│ ④ 底栏   计数 · 状态 · 动作            [定]      │  ← 没有就不画
└─────────────────────────────────────────────────┘
```

类名：`.墙` > `.墙顶` / `.墙身` / `.墙底`（已在 `页/组件.css`）。

| 区 | 放什么 | 不放什么 |
|---|---|---|
| **① 顶栏** | 面板标题 · 一句副题 · **至多一个主操作钮** · 模型条那类全局件由外壳管，不放这儿 | 不放搜索框（那是工具条的事） |
| **② 工具条** | `.分段`（互斥视图）· `.搜框` · `.选`（筛选项） | 不放动作钮 |
| **③ 身子** | 三种排法之一（见第三节） | 不许再嵌一个滚动区 |
| **④ 底栏** | 左边"已选 N 个 / 共 N 条"，右边动作 | 不放标题 |

**为什么只留一处滚动**：两个滚动条套在一起，用户分不清在滚哪一层，鼠标滚轮还会"卡住"。

## 三、身子的三种排法

### 甲、左栏 + 主体 + 已选栏（挑东西用）

```
┌──────────┬──────────────────────────────────────┐
│ 分类栏    │ 主体                                  │
│ (可滚)    │ 卡片网格 / 纵向清单                    │
│          │ (可滚)                                │
├──────────┴──────────────────────────────────────┤
│ 已选 3 个              [清空] [存进收藏] [复制]    │
└─────────────────────────────────────────────────┘
```

- 左栏 `220–240px`，`flex: 0 0 auto`；主体 `flex: 1`。
- 左栏每一行：`色点 · 名字 · 计数`（`.类项`）。**颜色来自数据**，不是界面编的。
- 主体两种：**卡片网格**（`.卡片们`，一眼扫很多个）或**纵向清单**（`.清单`，逐条读）。
- 已选栏只在"挑东西"时有；不是挑东西的面板不要硬加这一条。

### 乙、左栏 + 右栏（一边进、一边出）

```
┌────────────┬────────────────────────────────────┐
│ 来源        │ 结果                                │
│ (输入 / 图) │ (分组清单 / 对照)                    │
│            │                                    │
└────────────┴────────────────────────────────────┘
```

- 两栏宽度按用途给：`1fr 1fr`（对照）· `360px 1fr`（来源是窄的）· `1fr 1.4fr`（结果要宽）。
- 用 `.两栏`，窄屏自动叠成一列。
- **这一式没有已选栏**：它是"做一件事"，不是"挑一批东西"。

### 丙、分节表单（东西多、要一处一处看）

```
┌─────────────────────────────────────────────────┐
│ ① 工具条：请求 [下拉]         [存] [丢] [状态]    │
├─────────────────────────────────────────────────┤
│ ▸ 预设这一套                                     │
│   [字段] [字段] [字段]                            │
│ ▸ 工具表                                         │
│   [行] [行] [行]                                 │
│ ▸ 世界书                                         │
└─────────────────────────────────────────────────┘
```

- 每一节是 `.块`，`.块 > h3` 是那一节的名字。
- 一节里的动作钮放**那一节自己的底行**，不堆到顶栏——**决定要在做出这个决定的地方执行**（边界规则 4）。
- 顶栏只放"整块面板级"的动作（存 / 丢 / 状态）。

## 四、十二块面板用哪一式

| 面板 | 键 | 版式 | 左欄 / 主体是什么 | 已选栏 |
|---|---|---|---|---|
| **标签** | `tag` | 甲 | 分类树 / 卡片网格 | 有（已做完） |
| **收藏** | `favs` | 甲 | “收藏”的页与类 / 卡片网格 | 有 |
| **标签组** | `groups` | 甲 | 组类型（角色组 / 普通组）/ 卡片网格 | 有 |
| **角色库** | `chars` | 甲 | 作品 / 角色卡片网格 | 有 |
| **图片** | `image` | 甲 | 存放地 + 收藏分类 / 图卡片网格 | 有 |
| **识图** | `vision` | 乙 | 工作区那张图 + 三个动作 / 结果分组卡片 | 无 |
| **装订** | `binding` | 乙 | 原文 / 切分后的格 + 装订 | 无 |
| **翻译** | `translate` | 乙 | 输入 / 译文与出处 | 无 |
| **世界书** | `worldbook` | 丙 | 书与条目 + 落点 | 无 |
| **comfyUI** | `comfy` | 丙 | 连接 · 工作流 · 提示词 · 队列 | 无 |
| **主 AI** | `主AI` | 丙 | 身份 · 流程 · 工具表 · 世界书 · 模型 | 无 |
| **全部动作** | `面板` | 甲 | 模块 / 动作清单 | 无 |

**说明**

- **甲与乙的分别**：甲是"挑一批东西出来"，所以有已选栏、主体是卡片或清单，能来回挑；
  乙是"这一件东西变成那一个结果"，所以左右有因果关系、没有已选栏。
- **`favs` / `groups` / `chars` 是新增的三块**（旧版有、现在还没有）：
  - `favs`：`position.list{位置:'收藏'}` 加 `position.members` / `record.batch`，与标签面板同一套动作，只是位置换一个；
  - `groups`：`record.groups` 一次给全部组（实测 38169 个），**只画两张身份表都不认的那些**（用户自己建的组）——
    库里原有的两种组各有各的去处（角色组与系列组都在 `chars` 那块），所以刚装好时这一块是空的；
  - `chars`：同上，只留 `是角色组` 的那些（实测 **34120 个角色组**），左边按**系列组**（`是系列组`，实测 4049 个）分作品
    —— 系列组的成员就是那个系列里的角色，反过来读一次就有每个角色的作品（见 `页/面板/组.js` 的 `作品表`）。
- **`chars` 与 `groups` 共用一块取数**：都是 `record.groups` 那一份，`组.js` 里的 `是角色组` / `是系列组` / `是自建组` 三个判据决定去哪一块。

## 五、甲式的细规矩

### 5.1 左栏

| 事项 | 规矩 |
|---|---|
| 宽度 | `220–240px`（分类栏比面板侧栏窄，免得挤掉主体） |
| 行高 | 28px（`.类项`） |
| 一行装什么 | `色点 · 名字 …… 计数` |
| 计数从哪来 | **数据给的**。模块没给就不显示，不许界面自己数一遍 |
| 层级 | 最多两级（页 → 类）。第三级改成"点进去看" |
| 「全部」那一条 | 放在最上面，与下面隔一条细线 |

### 5.2 主体（卡片网格）

| 事项 | 规矩 |
|---|---|
| 一屏大概几张 | 宽屏 6–8 张（`minmax(200–240px, 1fr)`） |
| 一张卡片放什么 | 一行主名（等宽字）· 一行译名（淡）· 一行角标（状态） |
| 卡片左边那条竖线 | **数据给的配色**（分类色）。没有配色就不画这一条 |
| 选中怎么显 | `aria-selected="true"` → 底色 `--点亮` + 主色描边 |
| 角上的小动作 | 只在 hover / 选中时露出来（`.卡片 .角`） |
| 一次画多少张 | **最多 240 张**，多的给一个"再显示 N 个"。几千条一次全画会把页面拖死 |

### 5.3 已选栏

| 事项 | 规矩 |
|---|---|
| 左边 | `已选 N 个`；一个都没选时说"一个都没选"，不要空着 |
| 右边 | 2–3 个动作，**危的那个在最右** |
| 状态 | 一个都没选时那几个钮 `disabled`，不要藏起来（藏了就不知道有这功能） |
| 选中活在哪 | **只在面板的内存里**，不落盘、不进会话（界面不做会话状态） |

## 六、四个公共面孔

不管哪一式、哪块面板，这四种情况都用同一副面孔：

| 情况 | 长相 | 类名 |
|---|---|---|
| **缺前置**（"先挑一张图"） | 面板里一行黄条 | `.提示.警` |
| **读着** | 一块虚线灰框 + 一句"读着…" | `.装填` |
| **空的** | 一行灰字说清"空在哪" | `.空` |
| **失败了** | 模块的回执**原样画** | `画回执()` |
| **这块面板要的模块没装** | 外壳在身子位置画一行红条，说缺谁、宿主给的理由 | `.提示.错`（外壳画） |

**不上弹窗**：这五种都不许用 `alert` / `confirm`。弹窗遮整页、在假 DOM 里是空壳、
也没法在一条流程里连起来看。

## 七、尺寸（一眼看着齐）

| 部位 | 值 |
|---|---|
| 面板顶栏高 | `44px`（与外壳顶条同高） |
| 工具条高 | `32px` |
| 底栏高 | `44px` |
| 分类栏宽 | `220px`（角色库那种名字长的给 `240px`） |
| 卡片最小宽 | `200px`（标签墙 `220px`） |
| 清单最大高 | `62vh`（`.清单` 默认） |
| 卡片间距 | `8px`（密）/ `10px`（疏） |
| 区块间距 | `12px` |

## 八、三件不做的事

| 不做 | 为什么 |
|---|---|
| **不给"进深"**：面板里不再开第二层侧栏 | 三层导航之后用户不知道自己在哪；要下钻就换主体，不换栏 |
| **不弹窗问路**：点一下卡片不弹框 | 挑东西的手感靠连续点击；弹框会打断 |
| **不画进度条** | 模块只报状态切换，没有百分比（判据②、界面设计.md §九） |

## 九、每块面板的蓝图

**这一节是施工图**：每块面板的四个区各放什么、几个钮、点下去走哪几步。
数出来的钮就是全部交互；多一个少一个都要先改这一节。

> **这一段按实现校对过一遍**（做完之后逐块对回源码）。**底栏只有甲式那几块有**：
> 乙式没有已选栏，丙式的状态与动作都在顶栏或各节自己的底上，所以都不画第四区。
> 下面每块表里写着"底 | 无"的，源码里就没有 `.墙底`。

读法：**顶** = ①顶栏 · **条** = ②工具条 · **主** = ③身子 · **底** = ④底栏。
`[主]` 是那个实心钮（一块面板至多一个）。

### 1. 标签 `tag` 甲式 —— 已做完

| 区 | 放什么 |
|---|---|
| 顶 | 标题「标签」· 副题 · `[重读]`（幽灵） |
| 条 | `.分段`：全部 / 查库 / 分类 / 收藏 / 隐藏库 / 改过的；`.搜框` |
| 主 | 左：分类树（27 页 + 201 类，带配色与计数）。右：卡片墙 |
| 底 | `已选 N 个` · `[清空]` `[存进收藏]` `[复制]` |

**流程**：进面板读分类 → 自动挖第一页第一类 → `record.batch` 铺卡片 → 点卡片选中 →
点角上「详」开详情弹框（详情 · 改 · 注释 · 隐藏/还原/删）。

### 2. 收藏 `favs` 甲式 —— 新增

| 区 | 放什么 |
|---|---|
| 顶 | 标题「收藏」· 副题 · `[重读]`（幽灵） |
| 条 | `.分段`：收藏栏 / 建页建类 |
| 主 | **收藏栏**：左栏列出所有页与类（带配色与"几类"）· 右栏是选中的那一格里的卡片墙。**建页建类**：两个独立的 `.块`（建一页 / 建一个类），各有自己的钮 |
| 底 | `已选 N 个` · `[清空]` `[移出这一类]` `[复制]` |

**流程**：`position.list{位置:'收藏'}` → 左栏列页与类 → 点一类 `position.members` +
`record.batch` 铺卡片 → 已选后 `position.detach` 移出。
**建页与建类是两块、两步**：先有页，才谈得上往页底下加类——合成一张大表单会让人以为要一次填完。

### 3. 标签组 `groups` 甲式 —— 新增

| 区 | 放什么 |
|---|---|
| 顶 | 标题「标签组」· 副题 · `[重读]`（幽灵） |
| 条 | `.搜框`（按组名筛） |
| 主 | 左：按成员数分「小组 / 中组 / 大组」三档；右：卡片墙 |
| 底 | `已选 N 个` · `[清空]` `[存进收藏]` `[复制]` |

**流程**：`record.groups` 一次拿全（实测 38169 个）→ **只留自建的那些**（既不是角色组、也不是系列组）
→ 按成员数分档 → 卡片显示 `组名` + `中文名` + `成员 N 个`。**一次最多画 240 张**，多的给"再显示"。
库里原有的两种组不在这块：角色组与系列组都在 `chars` 那一块。

### 4. 角色库 `chars` 甲式 —— 新增

| 区 | 放什么 |
|---|---|
| 顶 | 标题「角色库」· 副题 · `[重读]`（幽灵） |
| 条 | `.搜框`（按角色名 / 中文名筛） |
| 主 | 左：作品（由系列组的成员反查）；右：角色卡片墙 |
| 底 | `已选 N 个` · `[清空]` `[复制角色词]` `[复制角色词与特征]` |

**流程**：与标签组同一份数据（`record.groups` 里 `是角色组` 的那些，实测 34120 个），
左栏换成作品（`是系列组` 的那些，实测 4049 个）。两块共享取数：`组.js` 一份。

### 5. 图片 `image` 甲式

| 区 | 放什么 |
|---|---|
| 顶 | 标题「图片」· 副题 · `[上传图…]`（主）· `[重列]` `[体检]` |
| 条 | `.分段`（三个存放地：图库 / 会话图 / 识图工作区） |
| 主 | 左：收藏分类（带成员数）+ `[＋ 建一个分类]` + 「这一张」（挑一张时才有：`[收藏]` 或 `[取消收藏]`）+ `[看这一条的详情]`。右：图卡片网格（缩略图 + 标识 + 时间） |
| 底 | `已选 N 个` · `[清空]` `[删]` `[交给后面的面板]` `[存进收藏]` `[复制引用]` |

**流程**：`image/列{作用域}` → 缩略图走 `/缩略图?条目ID=…` → 点卡片选中（可多选）→
`[看这一条的详情]` 开一个小框（原图 + 尺寸 · 大小 · 类型 · 来源 · 变体 · 元数据）。
**详情不在身子下面摊开**：换一张就换一屏，那样反而看不清。`[删]` 与 `[交给后面的面板]` 只在只挑一张时可用。

### 6. 识图 `vision` 乙式

| 区 | 放什么 |
|---|---|
| 顶 | 标题「识图」· 副题 · `[上传一张…]`（主） |
| 条 | 无（三个动作在左栏底部） |
| 主 | 左（`1fr`）：工作区那张图 + `[本地识图]` `[读元数据]` `[AI 识图]` + 模型 `.选`。右（`1fr`）：结果按类别分组 |
| 底 | 无 |

**流程**：左栏挑图（工作区 + 图库同列）→ 点三个钮之一 → 结果按「原图内置 Tag / 模型识别 Tag
/ 元数据」三块铺卡片，每块带一个 `[复制]`。**工作区恒 0 或 1 张**，写之前先 `image/清空`。

### 7. 装订 `binding` 乙式

| 区 | 放什么 |
|---|---|
| 顶 | 标题「装订」· 副题 · `[切分]`（主）· `[装订（交给 AI）]` · `[清空]` |
| 条 | 无（方向那个 `.选` 放右栏底） |
| 主 | 左：原文 `textarea`。右：切分后的格（按颜色分块）+ 「有内容的格」统计 |
| 底 | 无 |

**流程**：左边贴原文 → `[切分]` → 右边铺格（`.块` 一块一格，配色来自切分结果）→
副 AI 那条路走 `[装订]`。**「有内容的格」由模块回答，界面不自己数**。

### 8. 翻译 `translate` 乙式

| 区 | 放什么 |
|---|---|
| 顶 | 标题「翻译」· 副题 · `[清空]`（幽灵） |
| 条 | `.选`（方向，选项从模块读）+ `[本地译]`（主）+ `[切分]` |
| 主 | 左（`对半`）：输入 `textarea` + 字数。右（`对半`）：译文（等宽、可选中）+ 出处高亮区 |
| 底 | 无 |

**流程**：左贴原文 → `[本地译]` → 右边出译文 + 「命中的词」那一行（带 `[复制 Tag]`）→
`[切分]` 把原文切成一格一格摆在译文下面。

### 9. 世界书 `worldbook` 丙式

| 区 | 放什么 |
|---|---|
| 顶 | 标题「世界书」· 副题 · `.选`（请求：主AI / 翻译 / 识图 / 文生图）· **状态标签**（草稿改过 / 干净）· `[存]`（主）`[丢]` `[重读]` `[状态]` |
| 条 | 无（测的输入框摆在"测命中"那一节里） |
