# 主AI模块调用示例

字段和错误码见 [接口.md](接口.md)，模块职责见 [README.md](README.md)。

## 组装

生产装配由对接层提供业务工具表：

```js
const 主AI = createMainAiModule({
  根目录: '<用户数据目录>/主AI',
  默认目录: '<项目根>/主AI模块/assets/预设',
  业务工具: () => 导出绘画工具表(),
});
```

端口模式可用内存适配器：

```js
const port = createMemoryAdapter({
  默认: { 主AI: { name: '主AI' } },
  业务工具: () => [
    {
      名字: 'drawing_generate',
      摘要: '根据提示词生成图片',
      参数: { 正向: { type: 'string', required: true }, 负向: { type: 'string' } },
      说明: { 正向: '本次生成使用的正向提示词' },
    },
  ],
});
const 主AI = createMainAiModule({ port });
```

## 读当前预设

```js
const 当前 = 主AI.执行({ 请求: '主AI' });
当前.工具表;   // 当前业务定义中启用的工具，schema来自业务契约
当前.模型;
```

## 工具偏好

预设可以保存工具摘要、各层级参数 `description`、启用状态、顺序和 `runtime` 附加文本。类型、必填项及字段结构始终来自当前业务工具表；业务表之外的工具名不能添加。用户文件里的完整旧 schema 在读取时不会覆盖当前 schema。文本字段支持空字符串，`runtime` 缺省时执行结果的 `附加文本` 是 `{}`。

`tools: []` 表示没有偏好覆盖，当前业务工具默认启用。停用工具时，预设只保存对应的停用差异。
