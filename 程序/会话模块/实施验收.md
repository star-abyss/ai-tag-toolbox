## 实施范围与基线

启动时工作区已有大量未提交修改。本次保存了相关源文件原文、SHA256 与 Git 状态，位置为 `work/session-implementation-baseline/`；该目录只用于本次恢复和审核，不是运行依赖。没有重置、提交或清理既有工作区。

新增会话模块及 `对接层/会话图片.js`、`会话执行.js`、`会话投影.js`。宿主只装一份会话、图片与主 AI；会话作为应用模块加入交付面，主 AI 默认工具仍由七个业务模块生成。DSH apply 不装独立会话文件库。

图片存动作在原队列内执行注入的接收规则；清空在原队列内枚举。工具登记显式选择输出格式化函数与运行上下文。独立回执的图像字节存入固定会话，以严格标记保存；DSH 继续使用自己的 JSON 编码。ComfyUI 的五条可取消动作接收第三运行上下文的 signal。

独立会话管理统一走 `/toolbox/调`；`/对话/流` 只传实例、版本、变化/删除 ID。页面按实例、选择和列表/详情独立版本同步，草稿与发送按会话串行提交。消息与工具图像由唯一记录投影，停止/失败/未保存由实际状态显示。

旧独立对话管理源文件、测试和 `界面/助手.js` 已移除。旧 README 和设计原文在根 `旧设计/`，原文保留；旧本机用户数据没有读取、迁移或删除。DSH 对话桥属于 DSH 模式，保留其自身接口。

## 自查与验证边界

按 code-review 的需求轴与仓库标准轴顺序自查，以启动前快照区分既有修改，包含本次新增、已修改和移除文件；没有使用子代理。确认并修复：终态保存失败显示 complete、实际 HTTP 取消的未知工具结果误标 error、空库新建失败自动重试、非法写参数未返回 Promise、合法 null 工具回执被拒、实际页面挂载缺少草稿保存接线、会话更新没有刷新素材池。修复后对应检查均重跑通过。
