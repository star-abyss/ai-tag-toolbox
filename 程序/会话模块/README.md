# 会话模块

状态：实现与独立宿主接入已完成。模块行为、HTTP/工具执行、客户端时序和浏览器验收见 [实施验收.md](实施验收.md)。

本模块管理会话记录、草稿与一轮执行的生命周期。采用与本仓库其他模块相同的 CommonJS、唯一门面、纯逻辑核心、注入端口、文件与内存适配器。图片文件仍属于图片模块，模型请求与业务工具循环仍属于装配层。

## 本次实现范围

- 新建、列出、读取、改名、草稿、编辑消息正文、发送、重新生成指定轮次回复、停止、读取/回答/取消当前会话提问、清空记录、删除、重试保存、带图片导出导入。
- 会话图片由图片模块分配稳定图号；消息附件和业务工具结果引用同一图片记录。
- 独立宿主、现有助手页、图片区、工具回执与消息渲染接通。
- 移除被替换的运行代码和管理路由，更新现行文档与回归。

本次采用整条模型回复；线性消息记录；每会话一个 JSON；单文件自包含 JSON 归档。实际接口中没有分支树、发送队列、插队、摘要、自动裁剪、自动重试、通用事件总线或存档迁移。

## 文件

```text
会话模块/
  index.js                冻结门面、唯一动作表、工厂出口
  core.js                 会话操作、短提交队列与执行生命周期
  data.js                 本模块数据检查、复制、归档引用重建的纯函数
  port.js                 存储、图片、执行端口契约检查
  adapter-file.js         唯一使用 fs/path 的会话文件实现
  adapter-memory.js       相同存储契约的内存实现
  test/run.js             模块行为验收
  test/接口.js            字段与动作契约验收
  test/假端口.js           内存图片与可控制的假执行器
  package.json            无运行依赖，type=commonjs
```

所有跨模块调用只经过各自 `index.js`。文件根目录仅由装配层提供。运行时不读取旧格式、不生成兼容别名、不沿用导入会话的活动 ID。
