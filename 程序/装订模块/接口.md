# 装订模块 · 接口契约

> 本契约含 AI 装订入口与供翻译模块共用的纯文本端口。设计取舍见 [装订模块设计.md](装订模块设计.md)，示例见 [调用示例.md](调用示例.md)。

## 一、对外操作

### `切分`

```text
装订.切分({ 文本 }) -> 单元数组
装订.run('切分', { 文本 }) -> { ok:true, data: 单元数组 }
装订.文本处理.切分(value) -> { 文本, 单元, 退化 }
```

`单元` 按原始输入顺序排列，每项含 `标识`、`前`、`词`、`后`、`原文范围`、`词范围`。标识在本次切分内唯一。各范围是 `[start,end]`，以原始输入 UTF-16 下标计，左闭右开。原文范围包括括号、权重等壳，不含项间分隔符和外围空白；词范围覆盖实际待替换文本。空项保留。拼装从原文保留壳、分隔符、外围空白、空项和外围换行；词范围内部使用回传译文。无法按现行语法解析时由 `退化` 标出，并保留原文。

### `装订`

```text
装订(文本, { 方向? }) -> Promise<回执>
run('装订', { 文本, 方向? }) -> Promise<回执>
```

方向为 `auto`、`en-zh` 或 `zh-en`，缺省 `en-zh`。`auto` 按整段输入猜测实际方向。成功回执为 `{ ok:true, 译文, 原文, 方向, 表, 统计 }`；失败为 `{ ok:false, code, reason, 原文 }`。装订按选定方向挑选需翻译单元，AI 结果与切分单元归位后，由同一次拼装生成译文和范围表。

表的每项含 `标识`、`前`、`词`、`后`、`原文范围`、`词范围`、`译文范围`、`库译名`、`AI译文`、`译文`、`出处`。译文字段仅存替换的词内容；`译文范围` 覆盖最终显示的完整项，含壳、不含外围空白和分隔符。统计记录总单元及库、AI、原词等实际来源。

AI 端口仍接收 `{ source, words, from, to }`，`words` 是需译原词列表；AI 返回原词键值表。缺少键或值非字符串时对应单元保留原词，其他项继续归位。相同原词键无法表达不同的上下文译法；回执仍为每次出现记录独立标识和位置。报文只含需译词，不含壳或库译名。

同时仅允许一次装订执行；并发调用返回 `TEXT_BUSY`。模块接住端口错误并返回失败回执，不自动重试。

### 门面成员

| 成员 | 形状 |
|---|---|
| `切分({ 文本 })` | 纯文本切分结果；失败给 `null` |
| `装订(文本, { 方向? })` | Promise 回执 |
| `译文(文本, { 方向? })` | Promise；成功给译文，失败给 `null` |
| `文本处理` | 冻结的纯文本端口对象 |
| `run(动作, 参数)` | 动作门面 |
| `actions` | `['切分','装订']` |
| `describe()` | 宿主动作说明 |

## 二、共用纯文本端口

`文本处理` 由装订门面提供，供翻译模块注入；它不含查词、模型或网络依赖。

| 函数 | 形状 | 作用 |
|---|---|---|
| `切分(value)` | `{ 文本, 单元, 退化 }` | 扫描原文并记录稳定范围 |
| `拼装(source, rows)` | `{ 译文, 表 }` | 按单元词范围替换原文，生成最终文本与译文范围 |
| `猜方向(value)` | `en-zh` 或 `zh-en` | 根据文本字符计数推断方向 |
| `需翻译(word, direction)` | 布尔值 | 判断单元是否含来源语言文字 |

装配层将 `装订.文本处理` 递给翻译工厂。翻译模块不直接 require 装订模块。对外动作 `切分` 与纯文本端口 `文本处理.切分` 的回执形状不同：前者只交单元数组，后者同时交回原文及退化状态。拼装只替换词范围，其余字节片段来自本次原文快照；不接收分隔符配置。

## 三、装配端口

```js
createBindingModule({ 查词?, AI翻译? })
```

| 端口 | 形状 | 说明 |
|---|---|---|
| `查词(words)` | 中文名或 `null` 数组 | 可选。输入原样词列表，按位置返回查词结果 |
| `AI翻译(report)` | 键值对象或可解析 JSON 文本；可返回 Promise | 可选。输入 `{ source, words, from, to }` |

缺少查词端口时，待译项全部交给 AI；缺少 AI 端口时，需要 AI 的调用失败。查词抛错返回 `TEXT_LOOKUP_FAILED`；AI 抛错返回 `TEXT_TRANSLATOR_FAILED`；不可解析响应返回 `TEXT_BAD_ANSWER`。

适配器 `createRealAdapter({ 认词, 取提示词, 发请求, 用途? })` 将宿主依赖转换成 `{查词, AI翻译}`。模块不自行读取提示词、配置或模型路径。

## 四、错误码

| 码 | 含义 |
|---|---|
| `TEXT_BUSY` | 另一次装订仍在执行 |
| `TEXT_NO_TRANSLATOR` | 没有注入 AI 翻译端口 |
| `TEXT_TRANSLATOR_FAILED` | AI 端口失败 |
| `TEXT_BAD_ANSWER` | AI 响应无法解析为键值对象 |
| `TEXT_LOOKUP_FAILED` | 查词端口失败 |
| `BIND_BAD_ARGUMENT` | 未知动作或无效入参 |
| `BIND_FAILED` | 动作执行失败 |

失败理由写作 `码: 人话`。所有装订失败回执带本次原文快照。
