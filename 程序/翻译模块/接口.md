# 翻译模块 · 接口契约

> 本契约描述翻译模块当前接口。设计取舍与被取代的决定见 [翻译模块设计.md](翻译模块设计.md)；装订门面的共用纯文本端口见 [装订模块/接口.md](../装订模块/接口.md)。

## 一、对外动作

动作名和本地动作参数不变：

| 动作 | 入参 | 成功回执 |
|---|---|---|
| `看模型` | `{}` | `{ 可用, 缺, 模型, 有查词 }` |
| `本地译` | `{ 文本, 方向?, 模型? }` | `{ 译文, 原文, 方向, 模型?, 表, 统计 }` |
| `切分` | `{ 文本 }` | `单元` 数组 |

动作表的 `run('本地译', ...)` 与 `run('切分', ...)` 成功均包装为 `{ ok:true, data }`；`data` 分别是翻译回执内容与单元数组。方向可为 `auto`、`en-zh`、`zh-en`。`auto` 按整段字符数确定实际方向，回执中的 `方向` 是实际使用的 `en-zh` 或 `zh-en`。动作失败回 `{ ok:false, code, reason, 原文? }`；翻译失败带本次输入原文。

## 二、装配与依赖

翻译工厂接收装配层传入的依赖：

```js
createTranslateModule({
  文本处理,       // 必须：binding.文本处理
  查词?,          // 可选：原样词数组 -> 中文名或 null 数组
  译?,            // 可选：本地模型端口
  默认方向?,     // 可选；缺省 auto
  默认模型?,     // 可选
})
```

模块不 `require` 装订、标签或模型模块，也不找路径。`文本处理` 是装订门面提供的冻结对象：

| 函数 | 形状 |
|---|---|
| `切分(value)` | `{ 文本, 单元, 退化 }` |
| `拼装(source, rows)` | `{ 译文, 表 }` |
| `猜方向(value)` | `en-zh` 或 `zh-en` |
| `需翻译(word, direction)` | 布尔值 |

切分单元含 `标识`、`前`、`词`、`后`、`原文范围`、`词范围`。标识在本次结果内唯一，重复词也各有标识。范围为 `[start,end]`，使用原文的 UTF-16 左闭右开下标。原文范围包括括号、权重等壳，不包括外围空白和项间分隔符；词范围只覆盖实际替换内容。拼装保留从原文复制的壳、分隔符、外围空白和空项；范围内部由译文替换。

## 三、本地模型端口

```js
译({ source, units: [{ id, text }], from, to, 模型? })
  -> { 模型?, units: [{ id, text }] }
```

`units` 只含本次需要翻译的单元，返回项按 `id` 归位，不按词名、顺序或标点数量猜配。重复词分别占一个标识。待译项缺失、返回项缺失或译文为空均使本次操作失败；失败结果带原文。模型不得另给一份整段译文覆盖逐项结果。

## 四、方向、查词与来源

`en-zh` 才调用可选查词端口；端口异常或返回非数组时按未命中处理，不产生独立错误码。

| 方向 | 处理规则 |
|---|---|
| `en-zh` | 精确命中的标签采用库中文名；其余英文片段交给英中模型。混合项中已有中文片段保留。 |
| `zh-en` | 中文片段交给中英模型；混合项中已有英文片段保留。中文标签名不能用作英文结果。 |
| `auto` | 对整段文本计数后确定一个实际方向，并在回执中返回。 |

模型适配器可以在一个单元内部按来源语言片段处理；仍为该单元返回一条完整译文。混合项中已是目标语言的片段保留，视图按单元整体高亮。纯英文或纯中文句子作为整体翻译，不切成逐词结果。统计区分库译、模型译、原样保留及单元总数。模型失败不计作成功保留；完整译文与 `表` 由同一次拼装产生。

## 五、错误

| 码 | 含义 |
|---|---|
| `TEXT_LOCAL_BUSY` | 本地翻译仍有一次执行在飞 |
| `TEXT_LOCAL_NO_ENGINE` | 未注入本地模型端口 |
| `TEXT_LOCAL_NO_SPLIT` | 共用切分端口失败 |
| `TEXT_LOCAL_FAILED` | 模型调用失败或待译项结果不完整 |
| `TEXT_LOCAL_BAD_DIRECTION` | 方向不是 `auto`、`en-zh`、`zh-en` |
| `TEXT_LOCAL_BAD_ARGUMENT` | 动作或参数无效 |

失败理由采用 `码: 人话`。本地单次闸门在 `finally` 释放；页面协调最新输入与重试属于界面层。

## 六、对应表

表的每项包含单元 `标识`、`前`、`词`、`后`、`原文范围`、`词范围`、`译文范围`、`译文` 与 `出处`。来源为 `库`、`模型`、`原词` 或 `空`。`译文范围` 指最终显示文本中完整对应项的 UTF-16 左闭右开范围，包含保留的壳，不含外围空白和分隔符。由范围定位，重复词不会互相命中；句子按单元整体对应，模型不提供句内词对齐。

统计与表基于同一结果；界面不另行切分或按数组下标猜配。
