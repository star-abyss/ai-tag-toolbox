# 翻译模块 · 调用示例

接口字段以 [接口.md](接口.md) 为准，设计约定见 [翻译模块设计.md](翻译模块设计.md)。

## 装配

```js
const 翻译 = createTranslateModule({
  文本处理: 装订.文本处理,
  查词: (词们) => 标签.recognize(词们),
  译: 本地模型.译,
  默认方向: 'auto',
  默认模型: 'opus-mt',
});
```

模块接收装配层准备好的依赖，不自行加载同级模块或读取模型路径。

## 调用本地翻译

```js
const 回执 = await 翻译.run('本地译', {
  文本: '(1girl:1.2), long hair, long hair',
  方向: 'en-zh',
});
```

成功回执含最终译文、原文、实际方向、模型、逐单元表和来源统计。表的范围直接定位最终回执里的对应项：重复的 `long hair` 具有不同标识和范围。括号、权重、分隔符等均由拼装从原文保留。

## 本地模型端口

对每个需要模型翻译的单元，翻译模块传入唯一 ID 与文本：

```js
async function 译({ source, units, from, to, 模型 }) {
  // units: [{ id: 'u2', text: 'long hair' }, ...]
  return {
    模型,
    units: await 推理(units.map(({ id, text }) => ({ id, text }))),
  };
}
```

结果通过 `id` 回到对应单元。缺少待译单元或其译文为空时，本次失败并带原文，不把失败伪装成“保留原词后完成”。

## 方向

```js
await 翻译.run('本地译', { 文本: '猫坐在垫子上', 方向: 'zh-en' });
const 自动方向 = 翻译.猜方向('cat on the mat'); // en-zh
```

`auto` 依据整段字符计数确定实际方向，回执返回该方向。英译中查词命中项使用中文名；中译英不会用中文名覆盖模型结果。中英混合项按来源语言片段处理，已有目标语言片段保留。tag 壳、分隔符和外围格式由拼装保留；模型翻译内容内部的数字或标点由模型决定。

## 失败和重试

翻译失败返回 `{ ok:false, code, reason, 原文 }`。模型恢复后再次调用会真实重新请求。界面自动翻译通过 500 ms 防抖和“当前执行 + 最新待处理快照”协调修改；本地门面仍保持单次在飞闸门。
