# 翻译模块

本模块编排本地模型翻译。字段契约见 [接口.md](接口.md)，设计及已取代决定见 [翻译模块设计.md](翻译模块设计.md)，接线示例见 [调用示例.md](调用示例.md)。

## 职责与目录

翻译模块接收装配层注入的共用文本处理对象、标签查词函数和本地模型端口；本模块负责方向、选词、模型调用、按标识归位与统计。它不 require 同级模块、不查找模型路径，也不拥有页面输入状态。

```text
翻译模块/
├── index.js              门面
├── core.js               翻译编排
├── port.js               注入端口形状
├── adapter-fake.js       假依赖
├── adapter-real.js       真实依赖适配
├── test/run.js           模块自检
├── 接口.md                对外契约
├── 翻译模块设计.md        设计与决定记录
└── 调用示例.md            装配和调用
```

## 翻译流程

`切分` 记录每个单元的唯一标识和原文范围。`en-zh` 使用命中的中文名，其余英文来源项交英中模型；`zh-en` 含中文项交中英模型，中文名不作为英文输出。模型适配器在混合单元中只翻译来源语言片段，保留已有目标语言片段；纯英文或纯中文句子整体翻译。模型输出内容内部的数字或标点由模型决定。

模型端口用 `{id,text}` 返回单元，结果按 `id` 归位。译文及范围表经装订门面的 `拼装` 一次生成；壳、分隔符、空项和外围格式从原文保留，词范围内使用译文。结果表记录来源与范围，供页面双向高亮；重复词按位置区分，句子按整单元对应。

页面在输入停止约 500 ms 后触发翻译。页面只允许一次本地执行，并保存一个最新待处理快照；过期结果丢弃。输入变化会使旧对照失效，失败可重新请求。模型加载缓存保留，翻译结果缓存移除。

## 门面操作

```js
await 翻译.run('本地译', { 文本, 方向?, 模型? });
翻译.run('切分', { 文本 });
翻译.run('看模型');
```

动作清单和回执字段以 [接口.md](接口.md) 为准。本地动作参数保持 `文本`、`方向`、`模型`。

## 验证与边界

模块自检验证端口形状、按 ID 归位、来源和范围拼装、方向处理及失败回执。验收需确认混合输入中目标语言片段原样保留且来源语言片段有实际模型翻译；本地模型输出的语义质量仍须依据真实样本记录。

不得在模块里复制切分、拼装或模型查找逻辑；不得让界面从译文重新猜对应关系；不得添加未由用户要求的隐藏上限或自动回退路径。
