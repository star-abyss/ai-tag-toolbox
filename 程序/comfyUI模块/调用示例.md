# comfyUI 模块 · 调用示例

> **这份文件只回答一件事：怎么调。**
> 字段名与约束在 [接口.md](接口.md)；设计理由在 [comfyUI模块设计.md](comfyUI模块设计.md)。
>
> 里面的地址一律写成 `http://127.0.0.1:8188`，是 ComfyUI 的默认端口，不是本机的事实。

## 一、一分钟跑通

```js
const fs = require('node:fs');
const { createComfyModule } = require('./comfyUI模块/index.js');

// 存档：模块自己不碰盘，读写在装配层
let 档 = null;
const 存档 = {
  读: () => 档,
  写: (值) => { 档 = 值; return true; },
  清: () => { 档 = null; },
};

const comfy = createComfyModule({ 地址: 'http://127.0.0.1:8188', 存档 });

// 读取或更新本地生成设置，不请求 ComfyUI
const 设置 = await comfy.生成设置({ 每轮张数: 2, 最多轮数: 3, 自动迭代: true });

// ① 把 ComfyUI 里"另存为"出来的那张工作流装进来
const 图 = JSON.parse(fs.readFileSync('我的工作流.json', 'utf8'));
await comfy.工作流(图);          // 存工作流，直呼式：失败给 null

// ② 看它认出了什么
const 口 = await comfy.认();
口.认得的;      // ['正向提示词', '负向提示词']
口.可填;        // [{ 名:'正向提示词', 要:true, 现在:'…' }, …]

// ③ 按设置张数出图
const 跑 = await comfy.出图({ 正向: '1girl, solo, looking at viewer', 负向: 'worst quality', 张数: 设置.每轮张数 });
跑.任务号;      // '6d7441f0-…'
跑.产出;        // [{ 节点:'9', 种类:'image', 文件名:'example_00012_.png', 子目录:'', 类型:'output' }]
跑.填了的;      // { 正向:['6.text'], 负向:['7.text'], 图片:[], 张数:['5.batch_size'] }

// ④ 把图取回来
const 图 = await comfy.取图(跑.产出[0]);
图.字节;    // Buffer（与产出项那几个字段一起交回来）
图.mime;    // 'image/png'
```

**十二个动作一律返回 Promise。** 直呼成功给数据、失败给 `null`；
要失败理由就用 `run`：

```js
const r = await comfy.run('出图', { 正向: '…' });
if (!r.ok) console.log(r.reason);   // 'COMFY_UNREACHABLE: 连不上 ComfyUI：连不上（fetch failed）'
```

## 二、装配的三种写法

### 2.1 给地址（自带 HTTP 适配器）

```js
const comfy = createComfyModule({ 地址: 'http://127.0.0.1:8188', 存档 });
```

### 2.2 自己递端口

```js
const { createHttpAdapter } = require('./comfyUI模块/adapter-http.js');

const port = createHttpAdapter({ 地址: 'http://127.0.0.1:8188', 超时毫秒: 60000 });
const comfy = createComfyModule({ port, 存档 });
```

端口要有七个方法：`探活` `看队列` `看节点定义` `提交` `看任务` `取结果文件` `送图片`（见 接口.md §二）。

### 2.3 不碰真机（自检、界面预览）

```js
const { createMemoryAdapter } = require('./comfyUI模块/adapter-memory.js');

const comfy = createComfyModule({
  port: createMemoryAdapter({ 状态序列: ['running', 'success'] }),
  存档,
  等待: async () => {},          // 轮询不必真等
});
```

### 2.4 装配层的其余开关

| 开关 | 什么时候给 |
|---|---|
| `clientId` | 想让 ComfyUI 页面认出这个任务是这个页面发的（进度条能收掉） |
| `上限毫秒` | 大图 / 视频，默认 30 分钟不够 |
| `等待` / `现在` | 自检里换成可控的 |
| `新UUID` | 想自己决定界面图的 id |
| `取回` / `超时毫秒` | 只有自己做实验时才用 |

## 三、十二个动作逐个看

```js
// ① 探活
const 活 = await comfy.探活();
// { 版本:'0.34.0', 设备:'cuda:0 NVIDIA GeForce RTX 4070 SUPER', 显存总量:12878086144, 显存可用:5062784362 }

// ② 看队列
await comfy.看队列();            // { 运行中:0, 排队中:0 }

// ③ 看节点定义
const 定义 = await comfy.看节点定义();
定义.KSampler.input.required;    // 这个节点要什么参数（结果会缓存下来）

// ④ 存工作流（界面图或接口图都收）
const 存 = await comfy.run('存工作流', { 图 });
存.data.口.认得的;               // ['正向提示词', '负向提示词']
存.data.口.接口图;               // 提交用的那份

// ⑤ 取工作流
const 现值 = await comfy.取工作流();   // 与 ④ 同一个形状

// ⑥ 清工作流
await comfy.清工作流();          // null

// ⑦ 认（读存档里那一张）
const 口 = await comfy.认();
口.采样器;                       // 主采样器的节点 id
口.正向;                         // [{ nodeId:'6', classType:'CLIPTextEncode', input:'text', 文本:'…' }]

// ⑧ 认图（读递进来的那一张，不碰存档）
const 预看 = await comfy.认图(别的图);

// ⑨ 出图
const 跑 = await comfy.出图({ 正向: '…', 负向: '…' });

// ⑩ 取图
const 一张 = await comfy.取图(跑.产出[0]);
```

## 四、盯进度与取消

```js
const 控 = new AbortController();

const 跑 = await comfy.run('出图', {
  正向: '…',
  onEvent: (事件) => {
    switch (事件.类型) {
      case '已送图片': console.log('送图：', 事件.文件名); break;
      case '已提交':   console.log('任务号：', 事件.任务号); break;
      case '状态':     console.log('状态：', 事件.状态); break;
      case '完成':     console.log('产出：', 事件.产出.map((x) => x.文件名)); break;
      default: break;
    }
  },
}, {signal: 控.signal});

// 想停就停
控.abort();          // 之后收到 COMFY_CANCELLED
```

**一次只能飞一个**：上一次没结束就再叫一次，拿到的是 `COMFY_BUSY`。
想知道现在忙不忙，看同步的 `comfy.在跑吗()`。

## 五、图生图

工作流里得有图片口（`LoadImage` 之类的节点）。本模块只管把字节送上去、把回来的文件名写进图。

```js
const fs = require('node:fs');

const 跑 = await comfy.run('出图', {
  正向: '1girl, white dress, garden, soft light',
  负向: 'worst quality, low quality',
  图片: { 字节: fs.readFileSync('上一张.png'), 文件名: '上一张.png', mime: 'image/png' },
});
```

**降噪写在图里，不在参数里。** 想让降噪是 0.55，就在 ComfyUI 里把那张图生图工作流的
采样器降噪设成 0.55 再"另存为"，然后 `存工作流`。模块不替用户改采样参数。

送图与填口是分开的两步（`跑.填了的.图片` 会告诉你写到了哪几个口）：

```js
跑.填了的;   // { 正向:['6.text'], 负向:['7.text'], 图片:['20.image'] }
```

## 六、失败怎么办

| `code` | 人话 | 怎么办 |
|---|---|---|
| `COMFY_UNREACHABLE` | 连不上 | 看 ComfyUI 起没起、地址对不对 |
| `COMFY_NOT_JSON` | 那个地址不是 ComfyUI | 地址指错了 |
| `COMFY_NO_WORKFLOW` | 还没存工作流 | 先 `存工作流` |
| `GRAPH_NO_PROMPT` | 认不出正向口 | 到 ComfyUI 里确认这张图，重新导入 |
| `GRAPH_INVALID` / `GRAPH_EMPTY` | 图读不懂 / 空图 | 换一张图 |
| `COMFY_PROMPT_REJECTED` | 参数被 ComfyUI 拒了 | 看 `reason` 里的节点报错（含可选值） |
| `COMFY_SUBMIT_UNKNOWN` | 提交结果未知 | 到 ComfyUI 队列里看有没有这张图 |
| `COMFY_FILE_MISSING` | 产出文件不在 | 看那次任务真出了图没 |
| `COMFY_FAILED` | 执行失败 | `reason` 是 ComfyUI 的原文 |
| `COMFY_CANCELLED` | 被取消了 | 自己取消的 |
| `COMFY_TIMEOUT` | 等太久了 | 大图就把 `上限毫秒` 调大 |
| `COMFY_BUSY` | 上一次还在跑 | 等它回来 |

**全表在 [接口.md](接口.md) §四。**

要看细节（状态码、节点错误、任务号）就读 `run` 的信封：

```js
const r = await comfy.run('出图', { 正向: '…' });
if (!r.ok) {
  r.code;        // 'COMFY_PROMPT_REJECTED'
  r.reason;      // 'COMFY_PROMPT_REJECTED: 节点 3（KSampler）· Value not in list · sampler_name · 可选值：euler / dpmpp_2m'
  r.details;     // { 状态码:400, 节点错误:[…] }
}
```

## 七、工具脚本（不写代码也能跑）

```bash
cd 程序/comfyUI模块

# 按真机的节点定义造两张工作流（模型名从 /object_info 取，图生图的降噪由第二个参数给）
node tools/造工作流.cjs http://127.0.0.1:8188 0.55

# 对真机走一遍：端口七法 + 存工作流 + 认口 + 出一张 + 盯到完成 + 取图
node tools/连真机.cjs http://127.0.0.1:8188

# 拿一批工作流扫一遍，看认得出口的有几个
node tools/扫真实工作流.js <工作流目录> [节点定义.json]

# 核对提交带没带 client_id
node tools/验进度条.cjs <client_id>

# 两个子代理联调（一个当用户、一个当 AI）：说 / 交 / 出图的参数写成 @文件
node tools/联调.cjs 起 http://127.0.0.1:8188 文生图
node tools/联调.cjs 看
node tools/联调.cjs 说 '@要求.txt'
node tools/联调.cjs 问
node tools/联调.cjs 出图 '@参数.json'          # {"正向":"…","负向":"…","图片":"文件名"}
node tools/联调.cjs 取图 'example_00001_.png'
node tools/联调.cjs 交 '@回执.json'
```

**为什么参数写成 `@文件`**：Windows 的 PowerShell 往 node 传参时会把 JSON 里的双引号吃掉，
`出图 '{"正向":"…"}'` 这种写法在 PowerShell 5.1 上到不了 node。写成文件就与引号无关。
`tools/.工作流/` 与 `tools/.实测/` 是脚本自己的产物目录，`.gitignore` 里一条一个忽略掉了。
