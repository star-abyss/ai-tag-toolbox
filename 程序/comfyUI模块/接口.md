# comfyUI 模块 · 接口契约

> **一份能独立于实现存在的契约。** 它不是散文，是可以拿来校验的：字段名、类型、必填、约束、错误码都写死在这里。
>
> 改实现之前先改这里；改完这里，`node test/接口.js` 会告诉你实现跟不跟得上。
>
> 三组接口，边界各不相同：
> - **对外动作**（§一）：门面交出去的十三个。**只认工作流与提示词，不认地址与路径。**
> - **端口**（§二）：核心要求通信层提供什么。**核心通过它不认识 HTTP。**
> - **装配**（§三）：装配层递什么进来。

---

## 〇、约定

| 记号 | 意思 |
|---|---|
| `必` | 必填 |
| `选` | 可选 |
| `?` | 可能没有（`null` / `undefined`） |
| `串` / `数` / `真伪` / `对象` / `数组` / `字节` | `string` / `number` / `boolean` / `object` / `Array` / `Buffer` |
| `→` | 返回值 |

**两套命名，不许混：**

- **中文键 = 给人的**（动作名、回执字段、参数名）
- **英文键 = 给程序的**（工作流里的 `class_type` / `inputs`，产出项里的 `format`）

**十三个动作一律返回 Promise。** 两种调用法给两种信封：

| 调用法 | 成功 | 失败 |
|---|---|---|
| `run(动作, 参数)` | `{ ok:true, data }` | `{ ok:false, reason, code }` |
| 直呼（`comfy.认()`） | 数据 | `null` |

`reason` 的写法是 `码: 人话`。**模块不抛错**（装配阶段除外）。

**界面图与接口图**是工作流的两种形态，本模块两种都收：

```
界面图 = { id?, nodes 数组, links 数组, … }          ComfyUI 里"另存为"出来的那份
接口图 = { 节点id: { class_type 串, inputs 对象, _meta? } }   提交用的那份
```

## 一、对外动作

### 1.0 被多个动作共用的形状

```
口项   = { nodeId 串, classType 串, title 串, input 串, 文本 串 }
图片口项 = { nodeId 串, classType 串, input 串, 当前值 串 }
  张数口项 = { nodeId 串, classType 串, input 串, 当前值 数 }
产出项 = { 节点 串, 种类 串, 文件名 串, 子目录 串, 类型 串 }

口 = {
  format 数,                 图版本，现为 1
  节点数 数,
  采样器们 数组[{ nodeId 串, classType 串, 评分 数 }],
  主采样器 串|null,
  采样器不唯一 真伪,
  正向 数组[口项],
  负向 数组[口项],
  图片 数组[图片口项],
  张数 数组[张数口项],
  输出 数组[{ nodeId 串, classType 串, 类型 串 }],     类型：image | video | audio | 3d
  认得的 数组[串],            ['正向提示词','负向提示词','图片'] 里认得的那几个
  认不出的 数组[串],
  接口图 对象
}

填了的 = { 正向 数组[串], 负向 数组[串], 图片 数组[串], 张数 数组[串] }   每项是 '节点id.输入名'
```

**约束（不是建议）：**

| # | 约束 | 违反时 |
|---|---|---|
| 1 | **地址与路径不许出现在任何对外参数里** | 缺陷，不是错误码 |
| 2 | 一次出图同时只有一次在飞 | `COMFY_BUSY` |
| 3 | `存工作流` 收界面图时，`id` 不是合法 UUID 就补一个 | — |
| 4 | 填口不改入参：`填口` 给的是新图 | — |
| 5 | 图上没有负向口时，负向忽略；没有正向口时拒 | `GRAPH_NO_PROMPT` |
| 6 | 图上不收图片时给图片 → 拒；图片口已经连着线也 → 拒 | `INVALID_ARGUMENT` |

**界面图转接口图时，这几类节点不进接口图：**

| 哪类节点 | 怎么处理 |
|---|---|
| 标注（`Note` / `MarkdownNote`） | 丢掉 |
| 静音（`mode: 2`） | 丢掉；下游指向它的连线跟着没有 |
| 旁路（`mode: 4`） | 丢掉；下游指向它的连线**按类型接到它的上游** |
| 中转（`Reroute`） | 丢掉；下游指向它的连线接到它的上游 |
| 原型（`PrimitiveNode`） | 丢掉；它的值当成控件值写进下游那一格 |

控件的值在 `widgets_values` 里按定义顺序逐位取。**被转成连线输入的那些控件不占位**，
它们的值来自连线那一头（连到一个 `PrimitiveNode` 时就是它的值）。

LoraManager 界面图的 `properties.__lm_widget_ids` 与 `widgets_values` 逐项对应。
转换时按保存的名称提取节点定义中的输入；自定义控件类型也使用这份明确映射。
只供界面使用的元数据和列表不作为接口输入；已有连线保留，不被控件值覆盖。

### 1.2 `看队列`

```
入  {}
出  { 运行中 数, 排队中 数 }
```

### 1.3 `看节点定义`

```
入  {}
出  { 节点类名: 定义 }        /object_info 原样
```

| 项 | 规定 |
|---|---|
| 附带 | 结果缓存进核心；`存工作流` 与 `出图` 靠它补回界面图里被删掉的控件名 |

### 1.4 `存工作流`

```
入  { 图 必界面图|接口图 }
出  { 启用 真伪, format 数, 存于 数, 界面图 对象, 口 对象 }
```

| 项 | 规定 |
|---|---|
| 直呼名 | `工作流(图)` |
| 必做 | 先认口，认得出来才存 |
| 失败 | 图读不懂 → `GRAPH_INVALID` / `GRAPH_EMPTY`；没有存档能力 → `COMFY_STORE_REQUIRED`；存档没写进去 → `INVALID_ARGUMENT` |
| 边界 | `存于` 是当时的时间戳（毫秒数） |

### 1.5 `取工作流`

```
入  {}
出  { 启用 真伪, format 数, 存于 数, 界面图 对象, 口 对象 }
```

| 项 | 规定 |
|---|---|
| 失败 | 还没存过 → `COMFY_NO_WORKFLOW` |

### 1.6 `清工作流`

```
入  {}
出  null
```

### 1.7 `绘图开关`

```
入  { 启用 选真伪 }
出  { 启用 真伪 }
```

| 项 | 规定 |
|---|---|
| 读 | 不传 `启用` 时只读；存档没有该字段时回 `false` |
| 写 | 传布尔值时保存到存档记录顶层 `启用`；无工作流也能读写 |
| 出图 | 缺省关闭；关闭时 `出图` 回 `COMFY_DISABLED`，不请求节点定义、不上传图片、不提交任务 |
| 清工作流 | 保留开关值，只移除工作流字段；此时 `取工作流` 仍回 `COMFY_NO_WORKFLOW` |
| 在飞任务 | 关闭只阻止之后的新出图，不取消正在执行的任务 |
### 1.8 `生成设置`

```
入  { 每轮张数 选正整数, 最多轮数 选正整数, 自动迭代 选真伪 }
出  { 每轮张数 数, 最多轮数 数, 自动迭代 真伪 }
```

| 项 | 规定 |
|---|---|
| 读 | 不传设置字段时返回完整值；缺省为 `{ 每轮张数:1, 最多轮数:3, 自动迭代:true }` |
| 写 | 可只传一个或多个字段；未传字段保留原值；正整数与布尔值按字段类型要求 |
| 存放 | 现有存档顶层 `生成设置`；不需要工作流或网络；`存工作流` 与 `清工作流` 保留设置 |
| 限制 | 不设置最大数的隐藏上限 |

### 1.9 `参数`

```
入  { 节点 选串, 参数 选串, 值 选JSON }
出  { 节点 数组[{ 编号 串, 名称 串, 类型 串, 参数 数组[{ 名称 串, 值 选JSON, 类型 串, 选项 选数组, 最小值 选数, 最大值 选数, 步长 选数, 只读 选真伪, 说明 选串 }] }] }
```

| 项 | 规定 |
|---|---|
| 读 | 不传 `节点` 时读取工作流中全部节点参数；只传 `节点` 时筛选该节点。控件类型、选项与范围来自当前 ComfyUI 的 `/object_info` |
| 写 | `节点`、`参数`、`值` 同时传入时，更新存档中的原始工作流控件值；不建立第二份覆盖表。写后再次出图时转换进实际 `/prompt` |
| 连线 | 已连接输入标记 `只读:true` 并返回连接来源；写入已连接输入会报 `INVALID_ARGUMENT` |
| 界面图 | 保留原有节点布局、连线和界面属性；`widgets_values` 数组 / 对象及 `properties.__lm_widget_ids` 按实际控件映射读写，seed 的 `control_after_generate` 额外值不占错位 |
| 刷新 | 每次读取或写入都重新请求 `/object_info`，切换 ComfyUI 地址后使用新服务器定义 |

### 1.10 `认`

```
入  {}
出  { 认得的 数组[串], 认不出的 数组[串], 正向 数组[口项], 负向 数组[口项],
      图片 数组[图片口项], 张数 数组[张数口项], 输出 数组, 节点数 数, 采样器 串|null, 采样器不唯一 真伪,
      可填 数组[{ 名 串, 要 真伪, 现在 串 }] }
```

| 项 | 规定 |
|---|---|
| 读的是 | **存档里那一张** |
| `采样器` | 主采样器的节点 id；没有采样器时为 `null` |
| `采样器不唯一` | 图里不止一个采样器。**认口只认主采样器那一组**，其余采样器的文本节点不填 |
| `可填` | 恒三项：`正向提示词`（要: true）/ `负向提示词` / `图片` |
| `张数` | 主采样器 `latent_image` 的上游可确认批量入口；支持 `EmptyLatentImage` / `EmptySD3LatentImage` / `EmptyFluxLatentImage` 的 `batch_size`。`RepeatLatentBatch` 只支持直接接上述空 latent（同时将原始 `batch_size` 设为 1），或接单图 `LoadImage → VAEEncode`；其 `amount` 是重复倍数，不能单独视为绝对张数 |
| `现在` | 那一个口在当前图里的值，多个口用空格连起来 |
| 失败 | 还没存过 → `COMFY_NO_WORKFLOW`；图读不懂 → `GRAPH_INVALID` |

### 1.11 `认图`

```
入  { 图 必界面图|接口图 }
出  同 认
```

| 项 | 规定 |
|---|---|
| 与 `认` 的差别 | 读的是递进来的那张，不碰存档 |

### 1.12 `出图`

```
入  { 正向 选串, 负向 选串, 张数 选正整数,
      图片 选{ 字节 必字节, 文件名 选串, mime 选串 },
      onEvent 选(事件)=>void, 间隔毫秒 选数, clientId 选串 }
出  { 任务号 串, 状态 串, 产出 数组[产出项], 填了的 填了的 }
```

| 项 | 规定 |
|---|---|
| 顺序 | 检查绘图开关 → 读存档 → 取节点定义 → 认口 → 送图片（若有）→ 填口 → 提交 → 盯到完成 |
| 图片 | 字节先送进 ComfyUI 输入区，回来的 `文件名`（带子目录时拼成 `子目录/文件名`）再写进图片口 |
| 只给哪些项 | 没给的项一个字不动；`正向` 是唯一必须认得出的口 |
| 张数 | 只在明确传入时覆盖 `认` 报告的批量入口；显式传入但无入口时以 `INVALID_ARGUMENT` 失败，包括传 1；不重复提交任务。张数控制主采样器的批量，输出节点产出的附加文件仍全部保留 |
| 盯 | 默认每 1200 ms 看一次任务，超过 `上限毫秒`（默认 30 分钟）报 `COMFY_TIMEOUT` |
| 取消 | `信号` 一断，报 `COMFY_CANCELLED`（带 `任务号`） |
| 重入 | 上一次没结束就报 `COMFY_BUSY` |
| 提交失败 | 4xx → `COMFY_PROMPT_REJECTED`（参数被拒，`details.节点错误` 是逐条原文）；5xx 或没给任务号 → `COMFY_SUBMIT_UNKNOWN`（队列里可能已经有这张图） |
| 执行失败 | 任务状态里带 `error` → `COMFY_FAILED`，`reason` 里是 ComfyUI 的原文 |

**事件**（`onEvent`，按发生顺序）：

```
{ 类型:'已送图片', 文件名 串 }
{ 类型:'提交中', 填了的 填了的 }       开始实际调用端口提交前
{ 类型:'已提交', 任务号 串, 填了的 填了的 }
{ 类型:'状态', 任务号 串, 状态 串 }        状态一变报一次
{ 类型:'已取消', 任务号 串 }
{ 类型:'完成', 任务号 串, 状态 串, 产出 数组, 填了的 填了的 }
```

观察者抛错不影响出图。

### 1.13 `取图`

```
入  { 产出 必产出项 }
出  { 节点 串, 种类 串, 文件名 串, 子目录 串, 类型 串, 字节 字节, mime 串 }
```

| 项 | 规定 |
|---|---|
| 直呼名 | `取图(产出项)`：直呼时参数就是产出项本身，走动作表时是 `{ 产出 }` |
| 字节 | 交回的是**裸字节**（`Buffer`），与「取内容」一致。要过 JSON 的那几条路（工具回执、动作浏览器的 HTTP 面）各自在自己的边界上编成 base64 |
| 失败 | 参数不是对象 → `INVALID_ARGUMENT`；文件不在 → `COMFY_FILE_MISSING`；端口没给字节 → `COMFY_UNREACHABLE` |

### 1.14 门面上的其余东西

| 名字 | 是什么 |
|---|---|
| `run(动作, 参数)` | 走动作表，给 `{ ok, data }` 信封 |
| `actions` | 十三个动作名的数组（冻住） |
| `describe()` | `[{ 动作, 摘要, 参数, 说明 }]`，给模型看的那一份清单 |
| `ERR` | 三个文件的错误码表合并（见 §四） |
| `端口方法` | 端口要有哪七个方法（见 §二） |
| `在跑吗()` | 现在有没有一次出图在飞（同步，给真伪） |

## 二、端口

装配层递进来的那个对象要有这七个方法。**每个方法给 `{ ok:true, data }` 或 `{ ok:false, reason, code }`，不抛错。**

```
探活(信号)                     → { 版本 串, 设备 串, 显存总量 数, 显存可用 数 }
看队列(信号)                   → { 运行中 数, 排队中 数 }
看节点定义(信号)               → { 节点类名: 定义 } | { nodes: { … } }
提交(接口图, 附带, 信号)        → { 任务号 串 }
看任务(任务号, 信号)            → { 状态 串, 完成 真伪, 产出 数组[产出项], 错误 数组[串] }
取结果文件(文件名, 位置, 信号)   → { 字节 字节, mime 串 }送图片(字节, 文件名, mime, 信号) → { 文件名 串, 子目录 串, 类型 串 }

附带 = { clientId 选串, 界面图 选对象 }
位置 = { 子目录 选串, 类型 选串 }        类型默认 'output'
```

| # | 约束 | 违反时 |
|---|---|---|
| 1 | 七个方法一个不能少 | 装配时抛错并点名缺哪个 |
| 2 | 一律给结果对象，不许抛错 | 核心把异常收成 `COMFY_FAILED` |
| 3 | 失败时 `reason` 用固定几个词：`连不上` / `超时` / `权限` / `读不懂` / `不存在` / `未知` | — |
| 4 | `看任务` 里的 `状态` 是 ComfyUI 的原话（`running` / `success` / `error` …） | — |

**核心通过端口不认识 HTTP**：`core.js` / `graph.js` 里没有 `http`、`fetch`、`fs`、`path`。
`adapter-http.js` 是本模块唯一发请求的地方；`adapter-memory.js` 是自检用的假端口。

## 三、装配

```js
const { createComfyModule } = require('./comfyUI模块/index.js');

const comfy = createComfyModule({ 地址: 'http://127.0.0.1:8188', 存档 });
```

```
选项 = {
  port   选对象,                  给了就不装 HTTP 适配器
  地址   选串,                    与取地址二选一；固定地址，形如 http://127.0.0.1:8188
  取地址 选()=>串,                 与地址二选一；每次请求开始时读取当前 ComfyUI 地址
  存档   选{ 读, 写, 清 },         不给就没有存工作流的能力
  clientId 选串,                  提交时带的 client_id；未指定时由 HTTP 适配器使用独立客户端标识
  等待   选(毫秒, 信号)=>Promise,  默认 setTimeout
  现在   选()=>数,                默认 Date.now
  上限毫秒 选数,                  默认 1800000
  新UUID 选()=>串,                默认内置的 UUID v4 形状
  取回   选Function,              换掉 fetch（自检用）
  超时毫秒 选数,                  默认 30000
}
```

```
存档 = {
  读()        → 记录 | null
  写(记录)     → true（或 { ok:true }）
  清()        → 无
}

记录顶层可含 `启用` 与 `生成设置`；生成设置缺省值为 `{ 每轮张数:1, 最多轮数:3, 自动迭代:true }`。
```

| # | 约束 | 违反时 |
|---|---|---|
| 1 | 既没 `port` 也没 `地址` | 构造时抛 `COMFY_PORT_REQUIRED` |
| 2 | 端口缺方法 | 构造时抛错并点名 |
| 3 | `地址` 只能从装配层来，**模块自己不去读环境变量、不去探测、没有默认值** | 缺陷 |

## 四、错误码总表

| 码 | 出处 | 什么情况 | 调用方该做什么 |
|---|---|---|---|
| `COMFY_PORT_REQUIRED` | `core.js` | 装配时既没端口也没地址 | 改装配 |
| `COMFY_ADDRESS_REQUIRED` | `adapter-http.js` | 给了适配器但地址是空的 | 改装配 |
| `COMFY_STORE_REQUIRED` | `core.js` | 没递存档却要存/取工作流 | 补 `存档` |
| `COMFY_NO_WORKFLOW` | `core.js` | 还没存过工作流 | 先 `存工作流` |
| `COMFY_DISABLED` | `core.js` | 绘图开关关闭 | 勾选“启用绘图” |
| `COMFY_GRAPH_REQUIRED` | `adapter-http.js` | 提交的图是空的 | 先认口 |
| `GRAPH_INVALID` | `graph.js` | 既不是界面图也不是接口图 | 换一张图 |
| `GRAPH_EMPTY` | `graph.js` | 图里没有节点 | 换一张图 |
| `GRAPH_NO_PROMPT` | `graph.js` | 认不出正向提示词的口 | 到 ComfyUI 里确认后重新导入 |
| `INVALID_ARGUMENT` | `core.js` · `graph.js` | 参数形状不对（如图片给错、要填的口是连线） | 改参数 |
| `COMFY_UNREACHABLE` | `core.js` · `adapter-http.js` | 连不上 ComfyUI | 看 ComfyUI 起没起、地址对不对 |
| `COMFY_NOT_JSON` | `adapter-http.js` | 那个地址返回的不是 JSON，或不是 ComfyUI 的服务信息 | 看地址是不是指到别处了 |
| `COMFY_PROMPT_REJECTED` | `adapter-http.js` | 提交被拒（4xx），一般是节点参数不合规 | 看 `reason` 里的节点报错 |
| `COMFY_SUBMIT_UNKNOWN` | `adapter-http.js` | 5xx，或没给任务号 | 到 ComfyUI 队列里看有没有这张图 |
| `COMFY_TASK_REQUIRED` | `adapter-http.js` | 看任务没给任务号 | 改参数 |
| `COMFY_FILE_MISSING` | `adapter-http.js` | 产出文件不在，或空文件 | 看那次任务真出了图没 |
| `COMFY_BYTES_REQUIRED` | `adapter-http.js` | 送图片没给字节 | 改参数 |
| `COMFY_HTTP_ERROR` | `adapter-http.js` | 取文件 / 送图片的其它 HTTP 错 | 看状态码 |
| `COMFY_FAILED` | `core.js` | ComfyUI 报告执行失败，或动作里抛了错 | 看 `reason` 里的原文 |
| `COMFY_CANCELLED` | `core.js` | 信号断了 | 用户自己取消的 |
| `COMFY_TIMEOUT` | `core.js` | 超过 `上限毫秒` 还没跑完 | 看 ComfyUI 那边卡在哪 |
| `COMFY_BUSY` | `core.js` | 上一次出图还没结束 | 等它回来 |

## 运行上下文

`run(动作, 参数={}, 上下文={})` 和直呼的第二参数接收 `{signal?:AbortSignal}`。探活、看队列、看节点定义、出图和取图将其传入核心与通信端口。信号不属于业务参数；业务袋的 `信号` 不再作为取消来源。出图收到停止后保留已提交任务，不自动清队列或宣称回滚。
