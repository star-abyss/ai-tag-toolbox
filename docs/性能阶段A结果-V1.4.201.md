# 性能阶段 A 结果 V1.4.201

本轮完成了性能方案中的两项低风险优化，保留现有同步接口和用户可见行为。

1. 角色模块增加 `tags.characterNameIndex()`，只返回角色 ID、英文名、中文名、别名、成人标记和 count。角色首次加载不再通过 `tags.list()` 克隆完整 Tag 视图。
2. 普通 Tag 搜索输入、精度切换和清空搜索不再重建整个侧栏分类 DOM；侧栏只在分类、成人开关或路由变化时更新。
3. 角色数量继续从 manifest 读取，不会触发角色资料全文解析。

同一台 Windows 机器冷启动测量：标签库加载约 133.5 ms，manifest 计数约 0.3 ms，角色完整索引约 139.4 ms，角色中文搜索约 21.1 ms，精简角色名索引约 1.9 ms。单次结果受磁盘缓存和系统负载影响，只用于与同机后续版本比较。

验证：`npm run check` 52 项通过，0 失败；新增回归覆盖精简字段和输入搜索时侧栏节点稳定。没有运行慢 UI、smoke 或 ComfyUI 出图测试。

剩余优化按 [性能分析与优化方案-V1.4.200](性能分析与优化方案-V1.4.200.md) 执行：下一阶段把角色全文加载改为异步 Promise，随后再评估角色数据分片。阶段 B 会影响 UI、AI 工具和测试接口，作为独立版本实施。
