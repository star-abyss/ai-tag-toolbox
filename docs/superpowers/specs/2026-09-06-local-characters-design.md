# 本地角色资料设计

## 已确认的目标

- 主页 Tag 中增加角色库入口，替代原“角色名”浏览入口；人物数量、类型等普通分类保留。
- 不下载、不展示角色缩略图。桌面应用运行期间角色检索完全本地。
- 角色包含名字、别名、作品/来源、触发词、通用特征引用和专用特征引用。
- 通用新词补入现有库；学校、阵营、专属制服等集中放在隐藏共享表，只由角色资料引用。隐藏表无独立页面、普通搜索入口或 AI 工具。
- 角色查询自动展开引用，AI 和界面拿到完整文本；角色原始外貌只作参考，用户明确要求优先。

## 数据与兼容

当前来源为作者公开引用的 Laxhar/noob-wiki，版本 929c972dcc8aeecde42b7cd8931afe82cd864424。它不是 AniMadex 官网当前完整导出。
使用 33,599 条带 core_tags 的记录，原有角色名未被覆盖的仍作为仅身份资料可查。原始 CSV 和预审位于 F:/codex/animadex-data-20260906。
不修改 WD 模型索引。现有 Tag ID、用户自定义词、选中项保持兼容。新词采用人工确认的小批通用词，其余未解析词先保存在隐藏共享表并标记待复核，不自动猜测翻译或同义关系。
角色原始数据不加载进常规 Tag 的搜索索引；专用词从不经 addCustom 写入普通库。角色选择通过独立持久化记录保存，底栏汇总普通 Tag 与角色选择；取消角色不会取消用户手动选择的相同普通词。

## 页面

复用头部搜索框及精确/标准/宽松模式。角色库内搜索不清除作品筛选；普通分类仍保持原有行为。
页面为无图片列表和详情的双栏，窄窗口上下排列。作品/来源使用可搜索的筛选控件；角色列表分页，50 条一页，不受普通 Tag 的 1,000 条展示上限限制。
详情展示中英文名、作品、身份触发词、按现有分类分组的通用特征及专用特征，后两者默认不勾选。操作为“加入角色”“加入角色与所选特征”和复制；提供独立的作品词选项。
底部选中栏保持跨主页/AI/翻译持久化；角色作为可移除组合，拷贝文本时去重并转义角色限定词括号。
空结果、无特征旧角色、加载错误、成人开关、英文界面和分页状态必须可用。角色词不得注入 HTML。

## AI 接口

新增 characters.search(query, seriesId?, precision?, includeAdult?, limit?)，默认 5 条，上限 10。
返回名称、角色 ID、作品、identityTags、generalTags、specificTags；specificTags 是展开后的文本，无隐藏表入口。
agent.generateTags 增加 characterIds（最多 8 个）。主 AI 先检索再提交角色 ID，生成工具内部解析成带角色归属的 characterReferences，避免依赖模型把专用词重新拼凑。
生成器规则允许使用提供的角色资料作为参考，不能覆盖用户指定服装、颜色、人数。多人角色不得把全部特征混成无归属的全局列表。

## 验收

常规 tags.search 查不到新增的学校/阵营专名，characters.search 能从关联角色返回它们。新增通用词能查到并可选择。中文/别名/英文/作品检索、分页和收藏兼容经单元及 DOM 测试核对。
每个小步骤完成运行 npm run check 并提交。最终为 V1.4.198，不 push、不发 Release。最终同步桌面运行包和源码，包含相应 exe、app.asar、任务书、检查结果。默认不跑启动应用的慢测试。
