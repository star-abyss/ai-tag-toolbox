# 本地模型

模型目录固定在 `启动.cmd` 同层的 `模型/`，分为 `识图/` 与 `翻译/`。模型按一份模型一个文件夹放置：

```text
模型/
├─ 识图/
│  └─ wd-eva02/
│     ├─ wd-eva02-tagger.onnx
│     └─ tags-canary.json
└─ 翻译/
   └─ opus-mt/
      ├─ opus-mt-en-zh/
      └─ opus-mt-zh-en/
```

识图模型要求 `wd-eva02*.onnx` 和 `tags-canary.json`。翻译模型需要 `opus-mt-en-zh/` 与 `opus-mt-zh-en/`，每个方向包含模型权重、配置、分词器和词表。程序按文件结构发现 WD EVA02 与 opus-mt，无需 `模型.json`。完整文件要求见 `程序/对接层/模型引擎/目录.js`。

模型选择保存在个人数据根目录的 `设置.json`。模型根目录与个人数据目录无关，始终跟随启动器所在文件夹。

打包脚本默认建立这两个模型目录并复制 Markdown 说明，不复制权重；加 `-IncludeModels` 会包含模型文件。模型权重与词表不进 GitHub。模型来源和许可由用户自行确认。
