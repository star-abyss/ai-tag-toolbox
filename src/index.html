                👁 识图 API（独立配置）
                
                

                  
                  
                  
                  

                

                
主 AI 可以直接看图，也可以调用识图 API。识图 API 只输出绘图 Tag / 观察结果，结果仅作辅助参考。

                

              

              

                
              

              

                
                
              

              

              

                
                
              

              

                · 兼容所有 OpenAI
                格式接口（…/chat/completions），请求由应用主进程转发到你填写的地址；Key
                使用本机系统安全存储加密保存，不写入普通配置。
· 部分服务可能需要允许跨域或本地服务先启动；本地
                Ollama 需先启动服务。
· 使用「📷 图片反馈」需选择支持视觉的模型（如 gpt-4o /
                gpt-4o-mini、qwen-vl-max、Kimi 视觉版、deepseek-v4-flash-vision-exp、Ollama 的 llama3.2-vision
                等）；纯文本模型（如 DeepSeek deepseek-chat）收到图片会报错。
              

              

                🧩 固定 Agent Runtime
                
主 AI 只使用固定工具，页面不开放外部 Agent 写权限。

                  占位符，上方表单即这些参数。模型（Checkpoint/UNet/CLIP/VAE/LoRA…）全部由工作流决定，无需单独选择。占位符：{{prompt}}

                  {{scheduler}}。

              主提示词组 固定 5 个条目，可整体切换
            
            

              

                当前提示词组
                
                
                
                
              

              

                
                
                
                
              

              

                主提示词组固定包含 5 个条目：主 AI 提示词、文生图提示词、画师与品质词参考提示词、识图提示词、翻译提示词。
                不允许单独增加或删除条目，只能整组批量切换、批量导入导出；新建提示词组时自动创建 5 个空白条目，选中后生效。
                条目内容可单独修改，修改只影响当前提示词组。
              

              

                
                  1. 主 AI 提示词
                  主 AI 身份、可调用接口与调用时机、参数与返回、失败处理、停止条件
                  
                  
                
                

                

              

              

                
                  2. 文生图提示词
                  文生图主提示词 + 画师与品质词参考提示词
                  
                  
                
                

                

                  
                  
                

                

                  
                  
                

              

              

                
                  3. 识图提示词
                  提供给识图 AI：参考 Tag、视觉维度、不确定内容、输出格式
                  
                  
                
                

                

              

              

                
                  4. 翻译提示词
                  翻译方向、Tag 与专有名词保留、未知 Tag 处理、输出格式
                  
                  
                
                

                

              

              

            

          


          

            
              扩展提示词 仅对主 AI 生效
            
            

              

                
                
                
                
              

              

                扩展提示词只对主 AI 生效：不发送给识图 AI、翻译 AI 和文生图 Tag 子代理，不改变固定子代理的底层逻辑。
                两种启用方式：常驻（启用即发送）；关键词匹配（仅当用户输入包含指定关键词时发送，由系统判断，AI 不参与判断）。
              

              

              
暂无扩展提示词，点击「新增扩展提示词」创建。
