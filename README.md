# AI 绘画 Tag 工具箱

面向个人使用的本地 AI 绘画工具，集中处理标签整理、ComfyUI 出图、本地识图与翻译，以及 AI 对话中的绘画工具调用。

**当前版本：V1.5.20 · 模块化重写版。** 项目围绕独立能力模块、统一宿主和浏览器界面重新实现，程序、模型和个人数据分别存放。完整 Windows 下载包包含生产依赖及本地识图、翻译模型。

V1.5.20 支持 `EmptyFlux2LatentImage` 工作流的批量生成，并保留原有工作流的批量处理；补全文生图独立模型请求与图片元数据工具，统一翻译、识图和文生图的世界书执行。各请求可按顺序启用多本世界书。实现与验收入口见 [文生图请求与世界书执行](文档/文生图请求与世界书执行.md)。

## 下载与启动

1. 在 Windows x64 上安装 [Node.js 22 或更新版本](https://nodejs.org/en/download/)。
2. 下载上面的完整包，约 **1.48 GB**，解压整个目录。
3. 双击解压目录内的 `启动.cmd`。服务准备好后会自动打开系统浏览器，默认地址为 `http://127.0.0.1:8790/`。
4. 使用期间保留控制台窗口；关闭控制台即可结束服务。

完整包已经包含生产依赖、WD EVA02 识图模型和 opus-mt 双向翻译模型，解压后无需再安装这些依赖或下载模型。Node.js 需要单独安装。安装 Node.js 后若仍提示找不到 `node`，重新打开启动器。

Release 中的 `ai-tag-toolbox-v1.5.20-windows-x64.zip` 是运行包。GitHub 自动生成的 **Source code (zip/tar.gz)** 是源码快照，运行依赖和模型需要另行准备。

## 可以做什么

| 功能 | 内容 |
|---|---|
| 标签整理 | Danbooru 标签搜索、中文对照、分类、收藏、标签组和角色库 |
| 图片与识图 | 上传、图库收藏、读取 PNG 内置生成信息、本地模型打标及 API 看图 |
| 翻译 | 本地中英互译与 API 翻译，保留提示词权重和格式，提供原文与译文范围对照 |
| ComfyUI 出图 | 配置连接、导入工作流、修改节点参数、设置生成张数与迭代轮数、取回生成图片 |
| AI 助手 | 使用自己的 API 服务商和模型，在对话中调用绘画工具，管理图片附件及历史会话 |
| 提示词与世界书 | 分请求管理世界书，查看和编辑用户副本、工具文本及完整发送预览 |
| 会话管理 | 保存草稿、编辑消息、按轮重新生成、导入与导出会话 |

本地识图和本地翻译可离线运行。AI 对话、API 翻译和 API 看图需要配置相应服务；ComfyUI 出图需要可连接的 ComfyUI 实例与可用工作流。

## 首次配置

- **API 设置**：填写自己的服务地址、密钥与模型，按需要为主 AI、翻译和识图选择模型。
- **ComfyUI 设置**：填写 ComfyUI 地址并导入工作流，在同一页面调整节点参数和生成设置。
- **存储与模型**：完整包的模型已放在根目录 `模型/` 中，可在界面刷新并选择。个人数据位置可在设置中查看和修改。
- **提示词设置**：查看各请求的世界书与工具文本；需要修改内置正文时，先创建自己的副本。

## 程序、模型与个人数据

```text
工具箱-V1.5.19/
├─ 启动.cmd
├─ README.md
├─ 程序/                  运行代码、界面、依赖与内置标签资源
├─ 模型/
│  ├─ 识图/wd-eva02/       本地打标模型
│  └─ 翻译/opus-mt/        本地中英互译模型
└─ 文档/                  项目、架构与存储说明
```

个人数据默认保存在 `%LOCALAPPDATA%\工具箱\`，包括 API 配置、会话、图库、标签用户副本、预设、世界书和 ComfyUI 工作流。API 密钥保存在本机配置文件中，备份该目录也会包含密钥。

在界面更改数据目录后，下次启动使用新位置；程序不会自动搬移已有文件。需要保留数据时，先复制整个数据根，再切换位置。模型目录始终位于启动器同层的 `模型/`，与个人数据位置分开。

更新程序时保留个人数据和模型。重写版使用当前项目的存储结构，不自动迁移旧版存档。详细位置和备份方式见 [存储布局](文档/桌面版/存储布局.md)。

## 从源码运行

源码仓库包含代码、文档、测试和内置标签基础库。模型权重、运行依赖、个人存档及临时验收文件不进入源码仓库。

安装 Node.js 22 或更新版本及 pnpm 12 后，在 PowerShell 中执行：

```powershell
git clone https://github.com/star-abyss/ai-tag-toolbox.git
cd ai-tag-toolbox
pnpm --dir 程序/对接层 install --frozen-lockfile
.\启动.cmd
```

源码运行时，可从完整下载包复制 `模型/` 到项目根目录，或按照 [模型说明](模型/说明.md) 自行放置模型。未放模型时仍可使用标签、图库、ComfyUI 和 API 功能。

应用版本由 `程序/version.json` 提供，界面与打包脚本读取同一文件。

## 重写后的结构

七个能力模块平级：标签、图片、世界书、装订、ComfyUI、翻译、识图。模块通过各自门面提供动作，所需依赖由装配层传入。

主 AI 模块保存模型和工具设置，会话模块保存消息与执行状态；对接层装配能力、执行绘画业务并连接模型服务。浏览器界面与模型工具通过同一宿主使用这些能力，界面的模块动作统一经过 `/toolbox/调`。

## 验证与打包

常用检查入口：

```powershell
node 程序/tag模块/test/run.js
node 程序/对接层/test/run.js
node 程序/对接层/test/存储位置.js
node 程序/对接层/test/世界书请求.js
node 程序/对接层/test/复刻执行.js
node scripts/test-package.mjs <桌面包根目录>
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/test-run.ps1
```

依赖安装完成且本机离线缓存可用后，可生成新的桌面目录：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/打包.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/打包.ps1 -IncludeModels
```

默认只带模型说明；`-IncludeModels` 会复制根目录模型。打包脚本离线安装锁定生产依赖，保留正式说明，排除个人存档、测试、开发记录和临时文件。

V1.5.20 下载包已验证解压完整性、桌面启动与退出、会话和设置保存重启、本地识图及双向翻译；世界书与完整复刻链路使用本地模拟 API、ComfyUI 服务验收。当前发布验收未执行真实 ComfyUI GPU 采样。

已知问题：主 AI 可能在同一条回复中同时声明 `drawing_prompt` 和 `drawing_generate`，此时生成参数提前写定，不会采用尚未返回的文生图结果。需要使用文生图整理结果时，应在主 AI 世界书中明确先等待提示词返回，再在后续调用中生成。更新内置正文不会覆盖既有用户世界书副本。
