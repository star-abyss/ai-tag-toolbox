AI绘画Tag工具箱 V1.3.38

本版本包含三阶段架构调整的第一阶段，以及第二阶段的低风险边界整理和 AI 工作台交互修复：
- 提示词组装路径收口到 composeSystem
- 世界书运行时以当前 world.entries 为准
- 修复存储配额失败时的图片降级保存
- 会话图片改用 IndexedDB Blob + imageIds 引用持久化，避免 localStorage 膨胀
- 新增 AIClient HTTP 适配器
- 主进程 AI 请求、safeStorage API Key、AIJobController 和 PromptCompiler 已接入
- 标签搜索逻辑已独立为无 DOM 模块，便于后续 Worker / 虚拟列表升级
- 标签按钮改为批量渐进渲染，减少大标签库首屏卡顿
- 新增三来源中文译名并集与 SANL 英文别名数据，追加同义词不改变搜索算法
- 标签卡片下方按“主译名 / 中文别名”展示多译名，英文别名仍仅用于搜索
- 翻译页 AI 现已支持中文描述 → 标准 Tag，以及 Tag → 中文双向转换，并会把本站多译名、英文别名、分类和命中词作为参考发送给 AI
- 两个方向分别使用专用翻译指令：中文转 Tag 允许结合语义筛选/补充，Tag 转中文优先采用本站中文对照且不生成新 Tag
- 翻译请求会携带输入词、候选 Tag、多中文译名、英文别名、分类和命中证据，AI 可据此处理一对多词义
- 统一错误解释层：用户看到中文结论与处理建议，维护可依据错误码、HTTP 状态和脱敏摘要定位
- 新增 storageUsage 存储统计钩子
- 修复统一对话工作台本地识图无反馈、原图 Tag 无法折叠的问题
- 顶部 API / 提示词 / AI 助手改为带滑块动画的三段式切换栏
- 调整 AI 助手关闭按钮布局，避免与内容重叠
- 全站视觉系统刷新：统一按钮、标签、表单与深浅色主题配色，提升文字对比度
